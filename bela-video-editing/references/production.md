# 平台制作与复盘

按任务读取对应小节。当前项目简报保存已确认的画幅、字幕、口播速度、头像、音效和素材规则。

## 平台分支

| 平台 | 开工与构图 | 剪辑与检查 |
|---|---|---|
| 小红书 | 用手机画面和平台界面校安全区。以真实录屏或结果为主，头像放在逐镜确认的空位。已有字幕只校字时沿用样式 | 开头尽早出现可辨认的场景、结果或动作。教程把一个观看任务讲完整；局部放大要看得到目标和反馈。用实际画布核对单行或双语字幕的阅读空间 |
| 视频号 | 区分固定主题标题、素材区、独立强调字和口播字幕。用当前项目的字体、底色和字号，长词和双语检查完整 | 热点、关键解释或金句尽早出现。需要保留问候时接着进入主题。按有效成片速度审听字头、尾音、气口和引用上下文 |
| 两平台都做 | 共用原稿与源段映射，分开维护风格和平台遮挡区 | 只有选段与速度相同才共用字幕时间；否则分别校时，并分别检查片尾、字幕与发布入口 |

短视频项目先明确当前画幅。已有 9:16 视频母版的项目，继续用该画幅做视频预览和输出；另做静态封面时使用封面的独立规格。安全区以真实平台 UI 或经确认的模板为准。

## 人像、录屏与花字

- 先决定观众要看整体布局、真实操作还是局部结果。按任务保住完整窗口或输入、点击、反馈与结果。缩短等待时保留动作和状态边界；不要停在读不全的行上。相邻镜头查是否重复同一素材和源段。
- 头像或抠像沿用已确认形态。按动作最大的源帧检查头发、肩颈、手势、字幕和主证据。全屏真人切到头像时检查旧人像是否退出。叠层取同一句口播的源段和速度，按源起点与实际帧率换算；用户删句后重算，不能只平移外框。
- 做身后花字时，确认底片、花字与透明前景的层次，并校对同帧源映射、透明边缘及显示时窗。先在最难的短区间验证抠图，再接入母版。诊断底只用于查看边缘。
- 复用文字动效先看现有组件能否承担这句强调。花字跟随真实词级节点，落稳后让观众读清；检查与已有字幕、脸部和真实证据的遮挡。

## 镜头承接

同一件事跨镜头时，在现有分镜记下“口播节点 → 观众在看什么 → 下一镜接哪个对象或操作结果 → 在哪里读完”。用同一对象的位置、比例或运动方向引导视线，例如从工具截图接入同一工具的真实操作。先连续看最难的交接及其前后镜头，确认焦点延续和结果能读，再扩到同类镜头。换到独立场景且新焦点清楚时可直接切。

选翻页、推近、遮罩、切换或直接切前，先检查完成态。动态验收覆盖入场、最大形变、落稳和退出；抽帧用来检查位置、比例和遮挡。

## 音效与混音

| 画面动作 | 对齐点 |
|---|---|
| 逐字输入 | 对真实出现的字或短词配短键盘声，停打时停止 |
| 点击、发送或复制 | 对实际点击或状态反馈配短确认音 |
| 花字落位、卡片碰撞 | 把撞击重音对到可见落点 |
| 页面翻动、展开或移出 | 按可见动作选择纸张或短扫声，检查与前后音效的间隔 |

1. 在母版保留独立音效轨。先定位源音的有效起音、重音和可用尾音；入轨后回读实际源入点、时长和淡化。确认取段包含攻击点与需要的尾音；裁切后重算源锚点，再对齐可见动作。相邻音效冲突时按听感留尾、缩尾或换更短的源。
2. 回读片段增益、轨道压低量与输出设置，避免重复衰减。选一段含原声的代表样本，对比音效开关，用手机正常音量检查音效是否可辨、口播是否清楚。
3. 实际回听前保留听感待验状态。可用波形和电平定位静音、错锚点或截断，并提供同一母版的短试听供复核。

## 工具阻塞

主编辑器无法处理局部素材时，先判断缺的是源素材、编辑功能还是观察/试听能力。用已可用的原生功能或本地工具验证一个短片段；辅助片段接回同一可编辑母版。更换主编辑器前确认用户选择。缺真实证据的演示标注示意。

## 复盘与规则维护

仅在有实际剪辑或待复核积压时复盘。根据相关请求、用户纠正、时间线和明确对应的预览查证。修改时间、摘要与生成成功的提示可用于定位；只有实际检查才能支持验收结论。

按影响与复发成本处理少量独立根因，优先检查声音和字幕受损、证据错配、时间线不同步与遮挡。记录“证据 → 影响 → 现有规则 → 修复 → 验证与缺口”。规则已有但反复漏做时，调整原来的触发点或验收动作。单片坐标、曲目、增益和风格保存在本片简报；只有可复用的方法进入共享规则。修改前核对手调并备份，规则变更后用正常用例与反例回读。已锁定内容依本次授权处理。
