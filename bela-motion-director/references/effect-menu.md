# Effect Menu Reference

根据任务筛选、重命名或组合，不要每次机械输出全部选项。

| 效果 | 画面 | 适用场景 | 常见风险 |
|---|---|---|---|
| 逐字进场 | 字逐个滑入、弹出或被敲出来 | 开场标题、金句 | 字多会乱 |
| 重点字放大 | 一句话里只有关键词变大、变亮或轻震 | 痛点、结论 | 容易挡字幕 |
| 前后对比擦除 | 滑杆或扫光从旧效果切到新效果 | 设计前后、AI 前后 | 对比素材必须真实 |
| 卡片重排 | 杂乱卡片自动归位 | 工作流、分类、步骤 | 卡片过多难读 |
| 路径追踪 | 线条或光点带着文字移动 | 流程、地图、时间线 | 点位必须准确 |
| 视差层次 | 背景慢、文字快 | 氛围开场、B-roll | 容易只剩装饰 |
| 鼠标引导 | 光标、箭头或手势带出重点 | 真实录屏说明 | 不得伪造操作 |
| 字重变形 | 字号、字重、间距和倾斜逐步变化 | 字体、设计感演示 | GSAP 不能凭空造字体 |
| 节奏强调 | 关键词跟口播或音乐切换快慢 | 前三秒、字幕重点 | 节奏过碎影响理解 |

用户完全没方向时，先给三个案例方向：

1. 开场钩子型：第一秒快速出现关键词；
2. 前后对比型：普通效果变成设计后效果；
3. 字幕强调型：整句稳定，只有关键词动。
