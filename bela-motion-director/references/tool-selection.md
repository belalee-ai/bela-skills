# Tool Selection

## 默认选择

| 需求 | 首选 |
|---|---|
| 看文字、卡片、SVG 动效方向 | GSAP HTML demo |
| 稳定输出完整 MP4、精确时长、批量版本 | Remotion |
| 网页或产品页式结构化视频 | HyperFrames，先确认当前能力 |
| 已有网页动效并需并入完整视频 | GSAP + Remotion |
| 真实软件教程 | 真实录屏 + 少量说明动效 |
| 一个对象连续变成下一个对象、连续运镜展示 | onetake；先核实用途许可，不替代真实操作证据 |
| 从镜头配方制作单个镜头、2.5D 产品运镜 | video-shotcraft；读准确镜头卡与 demo |
| 界面交互的跟随、展开、弹簧与空间连续性 | apple-design 辅助已选制作工具；不单独负责导出 |

## 检查顺序

1. 当前是否有对应 Skill；
2. 当前项目是否安装运行依赖；
3. 是否能真实预览；
4. 是否存在视频导出链路；
5. 最终是否需要进入剪映。

Skill 存在只说明 Agent 有工作流知识，不证明项目已经可以运行或导出。

## GSAP 边界

- 优先动画 `x`、`y`、`scale`、`rotation`、`autoAlpha` 等变换属性；
- 少动画 `width`、`height`、`top`、`left` 等容易触发布局重排的属性；
- 逐字动画需要先拆分文字元素；
- 适合 HTML、SVG、标题、卡片和时间轴，不负责真人剪辑、口型同步和复杂电影镜头。

## 视频验证

- 抽查开头、中段和结尾关键帧；
- 确认编码、尺寸、帧率和音轨；
- 检查手机尺度、安全区、背景对比和遮挡；
- 需要剪映时说明兼容性是否真实验证。
