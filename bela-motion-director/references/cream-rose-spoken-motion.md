# 奶油玫瑰粉口播动效

2026-09-16，Lidali 明确认可 Markdown 省 Token 视频中新增的动效样式与颜色，并要求收入 Skill 复用。适用于真实录屏上的数字强调、概念关系和文件转换展示；作为已认可的可选风格，不替代其他已选风格。

触发方式：`用奶油玫瑰粉口播动效`、`沿用 Markdown 省 Token 那次的动效`。风格已确认时直接沿用，不重新要求选风格或确认相同 Demo；新构图仍检查完成态。

## 配色与形状

| 用途 | 参数 |
|---|---|
| 奶油底色 paper | `#FFF8F4` |
| 浅粉辅助底 soft | `#FFECEE` |
| 玫瑰粉强调 accent | `#E1668F` |
| 深梅棕文字 ink | `#49343D` |
| 文件纸张、反白文字 | `#FFFFFF` |
| 字体 | `Xinqingnian Ti`，常规 `400` |

简洁平涂、圆角卡片、线描文件图标和细箭头，数字为第一视觉重点。1080px 宽画布参考：外卡圆角20px，内部纸张/卡片10–12px，AI节点24–28px；描边2–3px，关系线4px。标题约36–46px，标签30–34px，数字约104px，按内容长度调整。颜色、文字、字体暴露为可编辑属性。

补充卡片可用860×300（数字）或860×480（关系图）作为起点，横向居中留110px；纵向根据实际录屏证据、字幕和人像安排，不固定套用原片坐标。主体只放短语、数字、图标与关系，一屏文字不超过5个；阶段切换时替换旧标签。

## 可复用动作

- **数字强调**：先出现已说出的数值，再在第二个数字开始说时显示该数字与连接符。透明度约0.13秒到1，缩放 `0.94 → 1.045 → 1`，约0.33秒归位。不要滚数到口播结束才给出结果；完整数字应很快可读，不反复弹跳。
- **问题展开为关系图**：小问题卡随讲解扩展，约0.47秒从小卡过渡到关系画布；文字、图片、连线和AI节点分别跟随各自语义出现。当前对象轻放大至1.045再归位；非当前对象可暂降到0.42透明度，再随讲解恢复。
- **文件转换**：两张错位纸张建立资料感；主纸张移动并以横向缩放 `1 → 0.12 → 1` 翻转，在最窄处切换文件标签，随后箭头推进到目标节点。参考翻转约1.23秒、箭头揭示约0.8秒。结论短标签在说到结论时上移18px并显现，约0.4秒。

动作时长是风格起点，语义触发时间必须由当前音频决定。运动结束后稳定停留供阅读，不持续晃动，不用额外装饰填满画面。

## 校时与叠放

- 先查对应词的真实时间点；只有整句或合并数字区间时，回听标记数字起音，不把ASR整段结束点当入场点。原片“54.27%出现太晚”的修正作为此规则依据；绝不复制原片绝对时间到新片。
- 先查现有时间线与用户编辑，再局部修改。保留底片连续音频、现有字幕、用户改过的文案和片段长度。
- 补充卡片避开整条字幕带、人物脸部和正在讲解的真实证据；无法避开时移动、缩小卡片或分时展示，不能靠遮住证据完成排版。
- 与 Bela 顶部进度条同片时共用玫瑰粉和新青年体；进度条自身仍保留方角与透明底板，不把卡片圆角或实色奶油底套到导航。
- 验收数字起音前、起音时、完全可读时和退出点，并连播回听一句完整口播。检查最终合成画面，不能仅凭动画参数宣称声画已同步。
