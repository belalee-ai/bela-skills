# B-roll 素材导演

先按 [需求确认](../bela-video-editing/references/intake.md) 读取本项目已确认的设置，补问会改变结果的缺项。优先使用本项目的参考图。任务明确采用李贝拉Bela 本人形象，或她的个人剪辑项目已确认沿用该形象时，才取用随包的人物参考。选择风格时，分别确认是否沿用示例中的人物、服装和配色。

逐个语义节点判断：真实操作/结果要证明就用录屏；数字、流程、分类、对比优先信息动画；本人经历或反应且人物能增加理解时才考虑真人/插图；抽象概念可选物体隐喻。人物模式、视觉风格、制作后端分别选择，不绑定套餐。

每节点交付 `原文或时间点 / 观众需理解什么 / 真实证据或示意 / 是否人物 / 风格 / 完成态 / 后端 / 接回位置`。不需要补画面的部分保留原片。

按需用 [视觉确认模板](references/visual-lock-template.md) 记录本条的画幅、主题色、风格、禁用项和完成态。有人物时读取 [人物身份与连续性](references/identity-continuity.md)，锁定本视频的参考来源、身份、服装、发型、饰品、可变动作与禁改项。实际查看参考图并注明用途。需要选画法、贴纸或日系线条时，查看 [五种风格与参考图](references/style-routing.md)。

使用已确认的素材先查重；确有缺口才制作。新方向先确认画面提案和一个静态完成态，再做短动画；样例通过后扩展。用户只要提示词就停在提示词。图片画幅和视频画幅分别确认，未答不自动使用 1:1 或 3:4。

按 [制作工具选择](references/backend-routing.md) 为每个镜头选一个执行工具。提示词用 `good-broll`，半调纸拼贴用相应的 `gbro-collage-broll` 或 `gbro-collage-info`，人物静帧用可用的图片生成工具。需要词级入场或可编辑图层时，用 ChatCut 原生 MG 或项目选定的本地动画工具。工具不可用时说明缺项。

拼贴动画要有真实透明分层，或使用已确认的首尾帧生成流程；不能将扁平图粗裁成多边形冒充独立贴纸。不自动改成弹跳、抖动或循环漂浮。每个镜头先定动作与停留职责。

从分诊方案、静态定版、动画与校时到最终文件，按当前交付范围使用 [B-roll 分阶段验收](references/quality-gates.md) 与 [主流程验收](../bela-video-editing/references/editing-qa.md)。没有唯一口播音频时，可交付无声样片或动作方案。交付时写明当前进度、文件位置和已核实的规格。
