# Visual Lock 模板

每条视频在第一张静帧前填写一次。用户确认后，它是本视频所有静帧、动画和生成提示词的共同上位约束。

## 1. 输出规格

- `画幅`：按确认值分别填写静态图和视频画幅，缺项再确认
- `尺寸`：按当前用途填写
- `主体模式`：P0 无人物 / P1 真人 / P2 手绘人物
- `风格编号`：S01 / S02 / S03 / S04 / S05 / 新风格候选

## 2. Character Lock

仅有人物时填写：

- `身份锚点`：使用哪些身份参考，作者形象按[人物参考说明](identity-continuity.md)取用
- `发型`：长度、分缝、轮廓、发饰
- `上装 / 下装`：类型、颜色、图案
- `配饰`：耳环、手表、手链、眼镜等
- `保持项`：整条视频不可改变的可见特征

真人和手绘可以切换，但同一视频的服装、发型、发饰和可见配饰不能切换。

## 3. Color Lock

- `纸底 / 背景色`：
- `墨线 / 主文字色`：
- `主题主色`：用户指定；未指定时按内容推荐并说明
- `辅助色`：可不使用；使用时占比低于主色
- `人物落色`：服装、配饰分别如何使用主题色
- `场景落色`：信息图形、箭头、卡片或物体分别如何使用主题色

主题色是视频变量，不是风格永久属性。换色时人物与场景必须成套更换，不能只改背景或单个图标。

## 4. Style Lock

- `不可变风格 DNA`：材质、线条、留白、构图骨架、图形语言
- `允许变化`：动作、景别、道具、分格内容、主题色
- `本镜头视觉命题`：一句话说明观众应该看懂什么
- `执行后端`：imagegen / good-broll 方法 / gbro 拼贴 / HyperFrames / Remotion / GSAP

## 5. Negative Lock

按本条视频列出：

- 不出现的服装、发饰和配饰
- 不使用的颜色、Logo、假字、假 UI、虚构数据
- 不允许漂移的人脸、发型和年龄感
- 不适合本风格的构图、材质和装饰

## 6. 确认状态

- `待确认`：只允许生成一张静态校准图
- `静态已确认`：允许生成同视频的其他静帧
- `动效已确认`：允许按唯一音频和字幕节点制作动画

任何锁定项发生变化，都要明确生成新的 Visual Lock；不能在同一视频中静默漂移。
