# 执行后端路由

选中制作工具后，读取当前环境中对应的 Skill 或工具说明，按实际能力选择执行步骤。

## 路由表

| 后端 | Skill 或工具 | 最适合 | 不适合 | 必须保留 |
|---|---|---|---|---|
| Good B-roll 方法 | `good-broll` | 文稿视觉化、风格词汇、场景和提示词 | 精确动画与最终视频验收 | 不强制固定人物；由本 Skill 覆盖身份与画幅规则 |
| gbro Collage B-roll | `gbro-collage-broll` | 约 5 秒抽象隐喻、纸拼贴逐件组装、生成式视频 | 精确图层、真实 UI、需要完全可编辑的时间线 | Gate 1 隐喻 → Gate 2 静帧 → Gate 3 视频；不得跳门 |
| gbro Collage Info | `gbro-collage-info` | P0 无人物的数字、流程、清单、对比和收敛信息动画 | 情绪独白、角色戏、假 UI | Gate 1 选段 → Gate 2 样帧 → Gate 3 HyperFrames/GSAP |
| imagegen | `imagegen` | P1/P2 人物静帧、身份校准、风格样张、概念完成态 | 精确多镜头时间线 | 沿用已确认的图片画幅，缺项再确认。标明输入图用途，输出保存进项目 |
| ChatCut 原生 MG / HyperFrames / Remotion / GSAP | 当前可用的对应 Skill | 精确时间轴、分层重排、字幕节点、可控遮挡和本地渲染 | 只需一张图或简单提示词 | 静态完成态先确认；动画结束帧与定版一致 |

## 选择规则

1. 真实证据镜头不进入生成后端。
2. 一个镜头只选一个主要执行后端；Good B-roll 方法可以作为前置策划，但不与两个动画后端同时重复生产。
3. 有人物身份要求时，[人物连续性](identity-continuity.md) 高于下游 Skill 的通用人物默认值。
4. 静态图片画幅沿用当前项目已确认设置，缺项时先确认。
5. 视频规格以当前项目和用户确认值为准；分别记录静态图和视频比例。
6. 没有真实音频时可以交付静帧、无声素材或动作方案，但不得声称已经按口播精确校时。
7. 想保留 gbro 的贴纸组装手感时，先检查静帧是否拥有真正可分离的透明图层。有分层才可转入 HyperFrames / Remotion / GSAP；只有一张已合成的扁平图时，使用 `gbro-collage-broll` 的空首帧→定版尾帧生成，不用粗略多边形裁切假装成分层。
