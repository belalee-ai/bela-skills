# B-roll 分阶段验收

## Gate 0｜授权与范围

- 当前交付是提示词、静帧、动画 Demo 还是最终视频？
- 是否需要外部付费模型？未经确认不扩大到付费视频生成。
- 是否有唯一口播音频和字幕时间轴？没有则不做精确校时承诺。

## Gate 1｜静态图片

- 图片画幅沿用本项目已确认设置。生成前补齐仍缺少的画幅。
- 主视觉只有一个；一屏主要文字元素不超过 5 个。
- 没有假字、Logo、水印、虚构数据或伪造 UI。
- 真实截图保持原比例，不拉伸。
- 图像已保存进当前项目，并验证实际像素尺寸。
- 项目指定做 Hallmark 复核时，优先局部修正并保留已确认方向。

## Gate 2｜人物连续性

- 不同角度能否辨认为同一个已确认的人物。
- 真人与手绘切换时，脸型、发型轮廓和年龄感是否对应。
- 整条视频的服装类型、颜色、图案是否一致。
- 整条视频的发型、发饰、手表、手链和其他可见饰品是否一致。
- 手指、手臂、身体连接是否合理；无多余肢体。
- 服装与画面配色协调，但没有无关品牌 Logo 或抢戏图案。

任一项不一致，回到静帧修复，不进入动画。

## Gate 3｜动画

- 动画从已确认的完成态反推，结束帧与静态定版一致。
- 元素按字幕对应词或语义节点进入，不提前剧透。
- 静态素材有观看动作；不做持续漂移或全片只用淡入淡出。
- 纸拼贴/贴纸动画是否保留 gbro 的组装骨架：干净纸底、3–6 个大纸组、逐件进场、一组一个主动作、卡位后稳定停住。
- 如果使用本地分层动画，每个运动组是否真正拥有透明独立图层；只有扁平完成图时，不得用带大块背景的粗略多边形裁片冒充贴纸。
- 风格差异是否主要来自材质、配色、构图、纸组数量和进场方向，而非额外弹跳、抖动、脉冲、扫动和贴纸雨。
- 截图、框线和标注若运动，必须处于同一容器同步。
- 无人物信息动画不突然加入角色；人物镜头不无理由换造型。
- 真实录屏与生成画面边界明确；还原内容标注为“还原示意”。

## Gate 4｜最终文件

- 用真实文件检查尺寸、时长、帧率、编码和音轨。
- 抽查开头、切换、复杂画面、后半段和最终完成态。
- 手机尺寸检查文字、脸部、主证据和安全区。
- 画面没有溢出、遮挡、空窗口、漂移和不可读的小字。
- 同一用途只保留最新确认图、最终视频和必要源文件。
- 清楚报告 `静态图已确认 / 本地已出片 / 已发布 / 待确认`，不混用状态。
