# 视觉风格路由

编号自 `2026-08-09` 起连续使用 `S01–S05`。旧编号替代关系：`旧 S04→S01`、`旧 S05→S02`、`旧 S06→S03`、`旧 S07→S04`、`旧 S08→S05`；新任务只使用新编号。

## 三轴分离

每个镜头独立记录：

1. `主体模式`：P0 无人物 / P1 真人 / P2 手绘人物
2. `视觉风格`：材质、构图、配色和图形语言
3. `动效语言`：组装、重排、翻面、路径、推焦、角色动作等

不要因为选择了某种风格就强行加人物，也不要因为人物是手绘就把整张画面都做成同一种模板。

## 贴纸动效继承规则

S01–S04 使用纸拼贴或贴纸媒介时，先继承 `gbro-collage-broll` 的动效骨架，再做风格差异：

- 干净纸底起步，不以完成页入场。
- 只分 3–6 个能被看懂的大纸组，一次只完成一个纸组的主动作。
- 默认节奏为 `结构 → 人物/卡片 → 连接或结果 → 稳定停住`。
- 使用滑入、放下、接合、卡位和必要的一次完成动作；不默认加弹跳、呼吸、扫动、冲击抖动或随机装饰。
- 风格差异由纸材、线条、配色、构图密度、纸组数量、进场方向和时长微调承担，不通过破坏运动物理来证明“风格不同”。

## 作者项目的校准示例

以下造型、配色和确认状态来自作者项目。复用某个风格时，先按本次人物和主题色确认要继承的部分。

### S01｜繁杂主义真人三视角拼贴

状态：`静态图已验证；动效待验证`

适合：同质化、信息过载、反复选择，同时需要本人承担操作/展示/质疑三个动作。

视觉：真人彩色剪影、奶油白描边、纸张颗粒、柔和物理阴影；高密度对象必须承载语义，人物脸部保持清楚。

参考：[参考图](../assets/styles/s01-maximalist-real-triptych.png)

### S02｜Apple 简约贴纸

状态：`静态方向已接受；动效待验证`

适合：工具推荐、产品能力、克制的观点解释和需要大量留白的画面。

视觉：暖白或浅灰背景、清晰单焦点、克制绿/珊瑚点色、轻描边和软阴影；不使用 Apple Logo，不复制专有界面。

参考：[参考图](../assets/styles/s02-apple-minimal-triptych.png)

## 静态已验证、动效待验证风格

### S03｜可爱贴纸风

状态：`静态图已验证；动效待验证`

人物锁：P2 手绘人物；鼠尾草绿宽松卫衣、短深棕侧分发型、无发饰、粉色手表与红绳。成人比例和本人脸型优先，不做幼态大眼或通用 Q 版脸。

画面锁：暖奶油纸底、粉彩水粉与轻彩铅质感、柔和不规则白色贴纸边；适合困惑、解释、生活化操作和轻松类比。构图优先温暖桌面、弧形信息关系和亲近的单焦点，不靠随机爱心、星星或闪光补可爱。

动效锁：保留 gbro 逐件贴入；可以使用更柔和的无过冲落稳，但不做放大镜往返扫动、人物循环呼吸或随机可爱装饰飘动。

正式参考：[参考图](../assets/styles/s03-cute-sticker.png)

### S04｜多巴胺贴纸风

状态：`静态图已验证；动效待验证`

人物锁：P2 手绘人物；珊瑚红主体、钴蓝袖子的撞色宽松卫衣，右侧青柠绿长方形发夹，粉色手表与红绳。五官和年龄感保持本人，不因高饱和画风变成另一名动漫角色。

画面锁：丝网印刷和剪纸海报质感，钴蓝、珊瑚红、亮黄、青柠绿和暖白形成受控色块；适合拒绝、切换、打散、加速和强观点。构图优先对角推进、页面扇形堆叠和动作线，不做全画面彩虹、随机贴纸雨或纯换色版可爱构图。

动效锁：保留 gbro 逐件组装；可以更快、使用更强的对向滑入，但不加左右抖动、色块脉冲、随机贴纸雨或为了“多巴胺”让所有元素同时动。

正式参考：[参考图](../assets/styles/s04-dopamine-sticker.png)

### S05｜日系线条风

状态：`静态图与动效已验证`

人物锁：P2 手绘人物；服装款式和配饰按本条视频单独锁定，并与主题色呼应。当前校准图使用白色宽松衬衫、主题色内搭、同色小耳环/指甲/细手环、无发饰、无手表和红绳。无论换什么主题色，都保留本人短发轮廓、脸型和年龄感，不变成通用日漫脸。

画面锁：极浅纸底、带轻微抖动和重叠感的细黑手绘线、大面积未填色留白、有限点色、思考气泡与三格视觉推演；适合评审、比较、解释、构思和抽象流程。主题色是可替换变量，不固定为荧光绿：用户可指定任意主色，必要时再配一个低占比辅助色；人物服装、配饰、信息图形和场景点色必须使用同一组色彩锁。构图优先人物工作桌、气泡分镜、线性箭头和大面积留白，不用西装符号、重水彩铺色、通用日漫背景、玻璃拟态、虚构图表或随机文艺摆件。

当前示例配色：青柠绿主色＋浅天蓝辅助色。它只是一次校准方案，不是 S05 的永久默认色。

正式参考：[参考图](../assets/styles/s05-japanese-line.png)

已验证动效语言：人物与桌面先在场，思考气泡使用细黑线逐段描出，三格内容按左→中→右分时落位，最后撤去临时覆盖层并回到唯一静态定版图。面板使用无过冲的平滑落稳，不使用弹跳、炫光、随机贴纸雨或完成页入场；无唯一口播音频时保持无声，不宣称字幕校时完成。

已验证动态样片使用 1080×1080、6 秒、30 fps、无音轨，动作顺序见上段。

换色要求：先记录 `纸底色 / 墨线色 / 主题主色 / 可选辅助色 / 人物服装落色 / 配饰落色 / 信息图形落色`。只替换点色系统，不改变白底黑线、留白比例、思考气泡、分格推演和线条质感。

待验证风格不得直接批量生产。先按本次确认画幅生成一张静态校准图，用户明确接受后，再把状态升级并添加参考资产。

## 新风格准入

每种新风格至少记录：

- 一句话定义
- 适用与不适用场景
- 配色、材质、构图和动效语言
- 是否支持 P0/P1/P2
- 禁用项
- 一张用户确认的静态参考
- 静态与动效分别标记验证状态

不要用颜色变化冒充新风格；结构、材质或运动表达至少有一项实质不同。
