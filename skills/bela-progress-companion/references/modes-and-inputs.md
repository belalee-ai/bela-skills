# 模式与输入

## 两个独立开关

| `labels` | `character` | 画面结果 | 适用情况 |
| --- | --- | --- | --- |
| `none` | `fixed-left` | 无分类文字，贝拉在安全左侧做轻动作，进度线独立推进 | 画面信息多，只要轻量品牌陪伴 |
| `none` | `follow-progress` | 无分类文字，贝拉坐在进度点上随进度移动 | 单线叙事、短视频或不需要章节名 |
| `chapters` | `fixed-left` | 有模块文字，贝拉固定在安全左侧，填充进度独立推进 | 模块清晰但不希望人物扫过文字 |
| `chapters` | `follow-progress` | 有模块文字，贝拉随进度移动并经过模块节点 | 教程、方法拆解、多模块口播 |

不把四种模式做成四套互不兼容的工程。保持同一组件，通过两个开关控制文字层和人物控制器。

## 最小输入配置

每次先在项目中记录等价信息，不强制使用某个文件名：

```json
{
  "canvas": { "width": 1080, "height": 1920, "fps": 30 },
  "durationSeconds": 60,
  "audio": "/absolute/path/to/voiceover.wav",
  "labels": {
    "mode": "chapters",
    "modules": [
      { "label": "开篇", "startSeconds": 0 },
      { "label": "为什么做", "startSeconds": 8.4 }
    ]
  },
  "character": {
    "mode": "follow-progress"
  },
  "targetEditor": "ChatCut",
  "output": "editable-source-plus-overlay-preview"
}
```

### 必填判断

- 真实画布和导入后素材分辨率；不得默认把 1080 素材放大到 1440 工程。
- 唯一口播音频与真实总时长。
- 是否显示分类文字。
- 人物固定还是跟随。
- `chapters` 模式下的模块原文和语义起点。
- 目标剪辑环境及其透明、混合模式或 Motion Graphic 支持情况。

## 模式默认判断

- 用户已经明确模式：直接执行，不重复询问。
- 有清晰的教程模块且没有表示想隐藏文字：推荐 `chapters`。
- 没有可靠模块结构：用 `none`，不要编造分类名。
- 用户强调“让小人带着进度走”：用 `follow-progress`。
- 真实界面内容密集、人物经过会挡证据：推荐 `fixed-left`，但必须通过安全区校验。

## 文字行为

- 只放模块关键词，不搬运整句字幕。
- 模块宽度首先服务标签完整可读，再对应口播结构；不机械等分。
- 上一模块进入完成状态后继续保留；进度不得切换时回退或闪白。
- `labels=none` 时同时移除标签、分隔线和它们的占位，不留下看似加载失败的空白。

## 人物行为

### `fixed-left`

- 贝拉固定在经过安全区校验的左侧锚点，不跟随进度点横移。
- 进度填充从她附近或组件真实起点向右推进，但不能穿过脸部。
- 使用克制、非机械循环的动作短语：呼吸、头部偏转、一次招手、腿部轻摆或节点反应。长视频按语义节点切换动作，不用 1–2 秒循环刷满全片。

### `follow-progress`

- 圆点与进度前沿共享单调递增控制器；人物以可见的 4–8px 惯性落后响应，而不是完全粘死。
- 在模块节点安排不同反应，例如招手、抬头、腿部摆动或轻回弹；动作不得提前泄露下一个章节。
- 人物完整边界始终在平台安全区内。开始与结束位置按角色外轮廓计算，不按圆心计算。
