# 小红书口播字幕样式

Lidali 已把「最近我找到一个手绘风格的图库。」这张样张定为本人小红书的长期字幕风格，它是当前优先的视觉基准。视频号字幕走[视频号分支](channels.md#2-视觉标题与字幕)，两边分别维护。

## 平台选择

- 先从当前任务确定平台，确定不了再问；不按当前打开的旧工程猜平台。
- 小红书读本文件：黑字、浅粉色横条底、有手写感的斜形字。
- 两平台共用素材时的字幕时间轴规则见[共用剪辑规则](editing-rules.md#账号与画幅)；换皮不重新剪动口播。

## 参考与实现

当前确认样张：[小红书个人字幕参考](../assets/xhs-subtitles/reference.png)，原始尺寸 2048×682。它用来同文对照字体、字距、倾斜感、黑字和浅粉横条；样张比例不是视频画幅，整张样张也不当字幕贴图。早期原图[图一](../assets/xhs-subtitles/IMG_2028.jpg)、[图二](../assets/xhs-subtitles/IMG_2029.jpg)只作辅助。参考图没展示全片位置、进出动画、音效或节奏，这些按当前视频定。

制作或更换小红书字幕样式时，加载本规范和确认样张，不重复选风格；本次有明确改法时按本次。只校错字、不改样式时，读目标字幕和当前覆盖值即可，不重新加载样张或套回旧参数。

| 项目 | 小红书规范 |
|---|---|
| 字形 | 黑色、有手写感的原生斜形；用户指定得意黑，工程按 Smiley Sans 配置。逐工程核对字体实际加载，配置值不能证明没有回退；与样张是否精确同款另做同文视觉对照 |
| 字重 | 用字体本身的实心笔画，关闭额外合成加粗；不用旧的宜颂默认，也不套视频号标题的 OPPO Sans |
| 文字色 | 纯黑 #000000，整句黑字；关键词默认不染绿 |
| 底条 | 浅粉色、平直横条，边角接近直角，文字上下留舒展的空白，横条可以横向铺开；不是紧贴字形的圆角胶囊。#FFDAE2 只是近似的制作起点，以样张和实际合成为准，不称截图精确取色 |
| 排版 | 单行，水平居中；长句按完整词和自然语义拆成前后两条，不压扁字形、不硬塞两行 |
| 附加效果 | 无描边、发光、立体挤出或明显投影；不加参考图里没有的装饰 |
| 斜体实现 | 优先保留字体原生斜形；同文对照仍不够时，只加一次小幅几何倾斜，不叠多个斜体变换 |

**1080×1920 初次试排值**（用户 2026-10-20 在 ChatCut 工程里亲手调整并要求记住，从实际预览的渲染样式读取）：得意黑 / Smiley Sans，字号 `49.68px`，字幕框 `x=131.49px / y=1451.7px / width=817.02px / height=153px`，水平居中；额外字距 `1px`、行高 `1.3`、底条上下内边距 `12px`、左右 `20px`、圆角 `2px`。作者当时的 ChatCut 工程；那次没有回读工程全局样式和单卡覆盖的分布，不假定每张卡都没有覆盖。

接续已有工程时先读当前字幕：用户后来手调的文案、字号、位置和卡片边界优先，不用上面的试排值覆盖。其他画幅等比适配，裁图宽高不当视频画幅。

## 时间、位置与验收

- 字幕沿唯一实际口播的时间轴同步；换样式时保持已锁定的时间、完整字词和尾音。
- 在真人底片上选字幕带，避开脸、操作证据、已有字幕和进度条。位置按[小红书安全区](xhs-editing-review.md#3-安全区是构图输入)的实际发布模板验收。底条可以延展，变换后的实际字形、斜体外伸和内边距必须留在可用区。
- 安全区在批量做画面和导出之前验证，覆盖所有同类页、素材内文字、导航和最长字幕。长句优先语义拆卡；变窄、硬塞窄栏或换字体都不是裁字的解法。
- 制作或更换样式时，先用真实字幕做一张静态定版或短预览，再渲染整条。在手机尺寸下查字形、底条高度、字距、单行宽度和对齐，优先用「最近我找到一个手绘风格的图库。」和样张同文对照。工程字体配置和参考图的精确匹配是两项检查，属性读取代替不了实际渲染验收。只校字时，只查受影响字幕的内容、显示边界和是否溢出，不重做定版。
- 渲染器缺字体或发生回退时明确报告，不悄悄换成默认黑体；字体名没确认，也可以先按已明确的黑字粉底样式出预览。
- 交付前核对本次平台和实际皮肤；只改小红书皮肤时，视频号规范保持不动。只更新 Skill 时不自动重渲染视频；已有视频编辑任务按其授权范围执行。

## 单行与专有名称

- 工具、项目、品牌和人名用用户确认的正式拼写；英文专有名词不强制译成中文或音译。普通英文词按语境中文化，但项目名称保持原文。手写风字幕不要求重绘真实网页和标志里的原生字体。
- 自我介绍和中英混排也按单行检查；只有明确做原文加翻译的双语字幕时才用双语分支，中英混排本身不是翻译字幕。长句先按完整语义拆成前后两张卡，正式名称尽量单独完整显示；不靠缩小整片字号、横向压字或让尾词掉到第二行解决。
- 单行以真实合成为准。重点看最长句、最长名称、自我介绍和重剪后边界变了的位置。ChatCut 原生字幕卡的单行修复步骤见[调用地图的 ChatCut 工程保护](skill-routing.md#chatcut-工程保护)。
- 用户同时在手调时，先回读最新修订，按最新明确的文字替换，不把旧句和新句追加到同一张卡。最终检查实际单行、完整拼写、手机安全区和没有双底条，“已写入”不算通过。

## 附加花字与网站名

针对本人小红书新增的花字、网站名和简短说明。花字在哪种场景用、怎么用，先按[样式卡](xhs-style-card.md#2-画面)区分：真人大画面可做身后沉浸花字，手绘纸面里字写进场景，不做只有字的页面。口播字幕仍是上面的粉底黑字；网站/作品本身的原生字体不重画；视频号的固定主题标题按视频号分支。

- 附加文字和字幕分工：网站名只报正式名字，花字只抓关键词，不把整句口播再做成一张卡。删掉左上/右上/左下那些没有观看价值的制作备注，避免多个文字层同时抢注意力。
- **网站名和附加花字不套字幕同色的填充块。** 默认透明背景，按实际背景选黑字或白字；必要时加少量反色细描边/轻阴影，或挪到稳定的留白处。对比问题不靠重新加大色块、底板来掩盖。
- 新增中文艺术字优先用已核实能加载的“新青年 / Xinqingnian Ti”，或用户确认的手写字体，不悄悄回退系统黑体。名字、花字和字幕不必同字体、同底条、同动效；用户当前手调优先。
- 对比度覆盖**整个出现时段**：入场、滚动时的明暗变化、交互、转场和出场。可以按源段切换黑白字，或给字形加轻量保护；只查首帧或中点不算通过。检查透明度动画会不会让入场/退场读不清，改字色后整段回看。
- 动效不全用渐显/渐进揭示。按语义从现有的 bela-text-motion-library 复用动作：大结论可以中心缩放或放大震动，汇总可以散字归位，网站名可以三维翻字或字距生长。强调动作后留出稳定的阅读态，不一直抖动，也不为多样化盲目加特效。
- 用户不确定选哪个时，给 [Little Move 动效库](https://belalee-ai.github.io/little-move/)，或 3–5 个实际编号、动作差异和适配的句子让她选；已明确选型就直接复用。动作库自带的音效不直接沿用，按[样式卡的音效色板](xhs-style-card.md#4-音效色板)配。
