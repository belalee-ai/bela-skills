# 小红书案例：网站、清单与排名类

2026-11-22 从[小红书分支](../xhs-editing-review.md)移出。只有本条做网站/设计素材合集、带排名或热度的清单、或贝拉 IP 探头姿势时才读；其他视频不加载。

## 网站与设计素材：先过选材关（2026-10-25 起）

- 先弄清这句话在介绍灵感库、整站模板、组件交互还是教程源码，再选对应证据。报出网站名不等于证明了特色；普通页头、人物简介卡、代码、T 恤/单件产品图替代不了整站设计和交互。说具体模板就展示那个模板，说鼠标追光就要出现实际追光，说图片展开就播放展开。
- 看源视频的真实运动，选高光入点/出点：整体版式建立 → 滚动进入有设计感的新区域 → 交互/动效完成 → 适当落稳。不从素材第 0 秒机械起用，也不只截作品集里几张静图往下滑。源码只在口播正在讲复用代码时短暂出现，不占设计效果的主时段。
- 优先用户提供的录屏、真实网站实录或可核实的官方作品。在素材表写明画面能证明的具体版本、对象与操作。缺历史版本、原参考或指定动作时，替代实录放在它实际能证明的口播句；必须同屏时，用简短的可见说明交代是现版、结果或演示。来源和许可留在素材记录，成片按本次要求处理网址、二维码和制作备注。
- 开头 20 秒先放最强、且对应口播的真实动态；20–30 秒的分类/总览用对应类别或多站预览，单个作者页不冒充整组网站。每站可以换不同的铺叠方式，但每个作品都要足够大、认得出。
- 缺真实证据或候选被否决后方向仍不清楚时，及时说明：盘点现有源片，显著影响选材时给 2–3 个真实候选让用户选，并继续其他确定段落，不批量制造无关替代。

## 清单型内容

- 可以用“编号与真实外观预览 → 各项亮点/适用场景 → 全名总结”建立预期。各项全名在介绍处完整显示，窄导航用能认出的短名，顺序绑定真实口播章节；章节名不用“截图/演示”这类制作工序。
- 有排名或热度时，核实统计平台、指标、时间和量级；累计安装不当独立用户数，单个平台榜单不外推全球市场。来源和统计时点记在内部，画面上的指标名要让观众看得懂。截图型清单检查所有行和数字落稳后的完整停留。

## Star 截图

- Star 截图是项目热度证据，不是质量星级。保留项目、仓库、统计时点和来源的对应关系，特别区分框架主仓和 Skills 仓库，一个仓库的数字不给另一个背书。用户截图按原字节和比例接入，不重画数字，不用放大的低清小裁片冒充高清；仓库归属没核实就记待核实。

## 贝拉 IP 姿势动作

- 先分清整图进出场、姿势切换和肢体动作。用户要扶边探头等具体姿势时，选用或制作对应姿势；整图平移/缩放不能说成人物在连续做动作。动作技术没验证时先做一个代表片段，身体拉扯、手抖、关节接缝或手和扶边不贴合都先解决，再批量应用。具体探头姿势和坐标只属当时那条片。
