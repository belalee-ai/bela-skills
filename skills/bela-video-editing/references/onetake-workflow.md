# OneTake Pro：剪辑工作流中的可选制作路线

只在选择连续动效或作品短片时读取本文件。普通真人剪辑、字幕、单个文字强调分别走总入口的对应路线。

## 2. 选路线

| 当前画面任务 | 选择 |
|---|---|
| 标题逐词、故障闪动、停顿打字、循环强调，已有001–030编号或配置 | 个人 `bela-text-motion-library`；直接取共用源码，不重新实现 |
| 输入框展开成窗口、卡片变为结果、一个对象贯穿多个状态 | OneTake Pro，记录每个边界保留的对象 |
| 独立工具/网页/Skill作品的短片，强调连续展示和镜头跟随 | OneTake Pro；按当前简报选择时长，不能把模板时长强加给口播 |
| 一般流程、地图、数据或已有 Remotion/HyperFrames 片段的局部修改 | 原工程或对应信息动效路线，不默认迁移 |
| 需要证明按钮、输入、运行结果确实存在 | 原始录屏/截图；动画只能辅助，不替代证据 |
| 要剪口误、重复试讲、长停顿，或只要字幕/进度条 | 总剪辑入口及对应组件，不进入 OneTake |

OneTake 不是个人视觉风格。颜色、字体、人物、画幅与安全区取本条已确认要求；不默认套原包横屏、70%留白、英文小字、模板配色或黑底结尾。用户指定了别的工具时遵循指定。

## 3. 从母版交给 OneTake

先锁定本条真实素材、唯一音频与目标时间窗。缺少录音时只写语义分镜并标待校时，不用平均时长猜触发词。

| 交接项 | 必须写清 |
|---|---|
| 任务 | 观众要看懂什么；独立短片或母版插片 |
| 母版 | 工程/时间线、实际画幅、fps、总长、接回轨道与全局起止帧 |
| 音频 | 唯一原声路径、触发词、真实词级时间；局部时间0对应哪一个全局时点 |
| 画面 | 关键词、已确认完成态、输入/中间/结果状态、跨边界保留的对象 |
| 素材 | 路径与来源、真实结果或还原示意、字体、人物资产与裁切 |
| 叠层避让 | 字幕带、脸部、操作证据、贝拉进度条、平台安全区 |
| 输出 | 源工程、片段精确帧数、画幅/fps、声音安排、能在哪一层编辑 |

## 4. 制作步骤

1. 读取指定 Pro 的原始 Skill 与本条已确认方案。有参考片时按原协议拆解；没有参考时从已有素材与简报设计，不杜撰参考数据。概念尚未选定时按原协议给不同中心构思；已确认概念不重复选。
2. 先做本条画幅下的关键帧/完成态。用户只要一张定版时，停在该交付；整段动画在本条制作范围内才继续。
3. 用单一 HTML、确定性 `window.__seek(t)` 与指定 Pro 的 `lib/motion.js` 实现。依赖按正确目录引用；不误引全局公开版的同名 `motion.js`。
4. 记录每个段落的进入、停留、退出、保留对象和触发词。完成态只在对应信息揭晓后出现，保留手机可读的停留时间。
5. 检查当前 Python、Playwright/Chromium、依赖、Node、ffmpeg/ffprobe 与字体；只核对本阶段需要的能力。脚本使用 Pro 路径，Python 可使用通过检查的已有环境。
6. 制作先低分辨率/低画质短预览，确认后按母版规格输出；配合本次允许的制作范围执行必要渲染，不把更新 Skill 当成制作视频任务。
7. 用原包 `probe.py` / `verify_promo.py` 做辅助检查，并实际回看最终文件。检查对象连续性、裁切、可读性、时长、时间对齐和声音；自动通过不代替视觉验收。

渲染器支持 `--width`、`--height`、`--fps`、`--scale`、`--dur`、`--sfx`。例如母版确认为1080×1920、30fps且竖屏布局已适配后，可用如下参数形式；工程与输出路径换成本条实际路径，运行前先检查依赖：

```bash
"$HOME/.codex/skills/onetake/.venv/bin/python" \
  "<OneTake Pro 源码目录>/scripts/render.py" \
  "/absolute/project/comp.html" --width 1080 --height 1920 --fps 30 --scale 1 \
  --out "/absolute/project/current.mp4"
```

宽高参数只控制渲染画布，不能代替修改模板布局。`--final` 会强制60fps与2倍缩放；母版没有该要求时不用。`--dur`是截取输出总长，不能靠截短掩盖未结束的动作。

## 5. 接回母版与可编辑性

- **OneTake片段**：保留自用源工程、素材引用与配置。MP4作为本条全屏替换画面或已有版式内的视频层接回；内部文字/卡片需在源工程改后重渲染，不能说成 ChatCut 原生可编辑组件。
- **透明叠层**：当前Pro渲染路径为RGB截图、`libx264 + yuv420p`，不保留alpha。需要透明且可编辑的标题、字幕或贝拉进度条时走原生MG/现有文字库；若明确要迁移动作，再单独适配验证，不承诺直接导入HTML。
- **时间**：片段局部0点绑定母版起始帧；导入后核对精确帧数和末帧。只替换画面时保留连续原声，不能按动画时长随意拉伸整段口播。
- **声音**：默认不另造配音或添加模板BGM。保留母版口播，只接必要SFX且压在人声下面；独立配音短片按本次需求再加载配音流程。
- **字幕与进度条**：沿用本条平台皮肤与用户手调值；叠层继续由对应Skill负责，不把字幕、贝拉导航重复烧进插片。替换或调整片段后检查遮挡和词级同步。
- **状态**：区分已准备、已实现、已出片、已接回、已导出、已发布。本次只有Skill更新时，完成文档和路由验证即可，不改当前视频、不启动AI自动编辑或付费生成。

## 6. 交付核对

报告所用源码版本、时间窗/触发词、源工程与片段位置、母版接回位置、可编辑层级、已检查的关键帧和声音切点。未知时间、依赖、授权凭证或导入状态分别标待核验，不以旧版本记录填充。
