# 视频号分支：粗剪、视觉与字幕、声音、验收

适用于 **Lidali 本人的视频号视频**。小红书、封面、课程、网页、红发魔女及其他作者走各自规范；平台没说清时先从当前任务上下文判断。当次明确要求和用户手调优先于本文件。本分支是后续默认，尚无发布效果数据验证。

画幅、每 3–5 秒有效视觉变化、剪口回听和整条复核是双平台共用规则，见[共用剪辑规则](editing-rules.md)。按需专项：

- 选镜、标题与注释分层、字幕缺行修复、选曲试听、ChatCut 局部返工 → [视频号制作与局部返工](channels-montage-review.md)
- 机器人、功夫等动作感强的配乐与卡点 → [急促弦乐、动作音效与混音](channels-action-audio.md)
- 新闻、真人热点 → [新闻解释专项](news-explainer-review.md)
- 单片坐标、帧号、响度等实例 → [视频号单片参数](cases/channels-samples.md)，只作调试起点

## 1. 粗剪与叙事

写稿和录音先读视频号口播说话风格〔资料：视频号口播说话风格〕：短句、问题推动解释、按作用分层、自然重音，保留本人声音，不模仿竞品声线或追赶其语速。

- **口播速度默认 1.2×**（本分支唯一定义处）。当次指定其他速度时按当次。只作用于本人口播，素材原声、背景音乐和其他作者另算。先定 1.2× 后的唯一口播时间轴，再同步字幕、画面、动效、音效和总长；保持自然音高，回听完整字头字尾和气口。
- 1.2× 是目标有效速度，只应用一次。接续工程先读当前口播相对原始录音的有效速度和源文件是否已变速，已达到就保持；只改画面或字幕时沿用已确认的声音与时间轴。源文件处理状态不清楚时先核对，文件名或单个速度参数不能作为依据。
- **删超过 0.6 秒的静音停顿和思考间隙。** 按原始录音、语义和波形定切点，保住完整字头、尾音和必要呼吸。当次给了别的阈值按当次；阈值只是排查入口。
- **删无意义的语气词和口头禅**：呃、嗯、啊、哦、那个、这个、然后、就是、其实、对吧、是吧等。它们承担指代、顺序、转折或个人情绪时保留，按语义判断，不按字符串全删。
- **删重复、结巴、口误和重说**，选完整自然的一次表达。观点、金句、案例、数据、情绪高点、因果连接和个人表达全部保留，压时长不以丢信息为代价。
- **叙事顺序**：热点、干货、金句前置；**保留开头问候**，问候后迅速进入重点，不用无关铺垫拖延核心内容。保持必要的因果、条件和引述上下文。
- **结尾**：弱化无关闲聊，落在具体判断、问题或行动上；仍有新信息或真实情绪的结尾保留。
- 先听原片的完整表达再选讲法，先按语义整理再清停顿。
- **紧凑也要留气口和重音。** 问句结束、转折、数字和新概念、金句前后，检查观众能否消化；句间停顿不削成同一长度。先用开头、难剪接缝和情绪句试听，再铺精细包装。整体过密先删重复信息，不继续叠加变速。语速快、剪口多都说明不了自然，以回听为准。
- **短片段看连续听感。** 不足 1 秒的“他说”等连接段，核对前后主语、字头字尾、音频把手和画中画嘴形；自然就留，突兀就重选完整源段。粗剪后和改切口后，听前后完整句和连续段落；处理喷麦时还要听爆破音、低频冲击和音色失真。没实际回听就登记风险和待验收，不写“已无吞字/喷麦”。
- **讲话、阅读、换镜是三种节奏。** 每 3–5 秒有效变化不等于每镜剪到 1 秒：小于 1 秒的非必要画面优先去掉或顺接后镜，1–1.5 秒的镜头也要看动作和阅读是否完成。检查源片内部切镜、黑场、片头尾卡和底层回闪，不只数时间线片段。图片、采访和关键动作按实际观看任务留够时间。
- **视频号的节奏补充**：按 1.2× 后的成片时间检查 3–5 秒窗口，变化落在对应口播语义节点上；信息密集处可以更短，不要求一律硬切。静态截图或网页停留超过 5 秒必须拆镜，或加入观众能感知、帮助理解的观看动作。验收时找出整条里超过 5 秒的同镜头区间，在真实合成或连续播放里确认有进展；“代码里有动画”不算证据。只换画面时不切断原声，也不为卡秒加重复字幕、小字或无关素材。
- 多观点集锦用一个观看承诺串起分段，可以在连续原声中句中换 B-roll；剪动原声时才按完整字词、气口和实际回听定切点。不要被教程的“一条一个功能”模板强行改成另一条内容。
- 变速、重排和删词后，字幕、素材贴片、动效、音效、进度和总长一起重校。保持语意连贯和个人表达，剪辑点自然、没有突兀跳切；用真实回听和连续播放验收，自动转写、淡化参数或剪口数量只是辅助。

## 2. 视觉、标题与字幕

### 版式与字体

| 层级 | 现行规范 | 使用边界 |
|---|---|---|
| 版式 | 深色底，上方标题，中间真实视频，下方字幕；纯中文单行，英文口播走双语 | 保持真实素材比例；不固定横屏素材或同一像素坐标 |
| 主标题 | 白色 `#FFFFFF`；中文、英文和数字都用 `OPPO Sans` 700；统一右倾 12° | 模板起点 82px、额外字距 2.5px、行间参数 22px，超宽自动缩小；自然框 1000×260，按真实文案长度和安全区检查 |
| 副标题 | 青柠绿 `#9CF93D`；字体组合、700 字重、右倾 12° 同主标题 | 模板起点 86px，两行紧凑；长标题不套四字花字的 12px 字距，太小就精简文字 |
| 中文口播字幕 | 得意黑，深色字 `#101415`，青柠绿圆角底 `#9CF93D`，单行 | 起点约 64px、圆角 14px；按语义断句，完整词不拆开，完整句子留在字幕里 |
| 英文口播字幕 | 必须中英双语；中文译文用上一行样式，英文原文在下方清楚显示 | 英文整句可用下方白字；中文口播里夹的英文词可在同一绿底字幕中分两行配中文释义。字号以手机可读为准（旧 40px 不再沿用）；保留原声，不新增配音 |
| 独立强调花字 | 白色 `#FFFFFF`，思源黑体 `Noto Sans SC` 600，适度均匀字距 | 四字样本起点 140px、额外字距 12px；长短文案按实际调整 |

- **配色按角色分**：白色给标题和强调花字，青柠绿给副标题和字幕识别，深色给背景和字幕字面。不把全部文字染绿。花字用白色，橙色 `#FF9B3D` 已停用。
- **标题字形**：OPPO Sans 700 的清晰粗斜字形、紧凑双行；正体只做一次向右 12° 几何倾斜，不叠原生斜体，关闭额外合成加粗。字形厚重、字腔通透、字间不黏连。可变字体显式锁定 wght 700，用实际渲染确认字重，参数和字体内部名字（如含 Thin）都不能单独作证。实色厚笔画，不加描边、发光、立体挤出或多色。英文清楚易读优先于装饰感。
- 字号和宽度按文案、画幅和安全区适配，每条真实素材单独检查。标题、口播字幕和独立花字各用各的字体与内容：得意黑只用于中文字幕，独立花字用直立清楚的黑体。
- **标题执行入口**：白绿粗斜双行标题模板〔资料：标题模板〕。当前复用以 ChatCut 内联 JSX/JSON 为准；目录里的旧本地 HTML、Noto 字体和旧 PNG 只是历史实现证据。新片替换文字、按实际画布放置，接入后看真实合成帧。
- 新片按真实手机播放界面和本片构图检查四边安全区、字幕、人物脸部和素材证据；样本工程的坐标不是平台安全区。

### 顶部标题与字幕的分工

- 顶部白绿两行是整条视频的**固定主题标题**：开场完整出现，默认全程保留。上行写人物、事件或核心观点，不随口播轮换成摘要或字幕。模板里的 `subtitle` 只指标题第二行，不指口播字幕。
- 底部得意黑绿底字幕按实际口播更新。词级触发用于底部字幕、主体花字和示意元素；固定标题不逐词揭晓。局部花字放在主体画面，不占标题区。
- 交付时抽查开头、中段、结尾：标题相同、字幕不同。用户明确要求例外时按当次。

### 字幕位置与双语

- **字幕放在素材下方，间距约为素材实际显示高度的 10%**：`字幕顶边 ≈ 素材显示底边 + 素材显示高度 × 0.10`。按画布中的显示尺寸算，不按原始分辨率、整张画布高度或文字基线；不把字幕固定到远离素材的底部坐标。
- 素材缩放、移动或裁切后重查可见边界；不同高度的网页、截图或视频可按镜头单独定位，避免压住正文。一条字幕跨两个镜头时两侧都查，避免切镜瞬间遮挡。
- 双语字幕作为一组，从上述顶边向下排，同时满足手机安全区和可读字号。空间不够先调素材构图或字幕排布，不缩成小字、不拉伸字形。以实际合成为准，当次指定位置优先。
- **口播出现英文，就同时给英文原文和中文理解。** 英文整句显示中文译文和英文原文；中文口播里的英文词、缩写或名称保留原文，配中文释义或必要说明，不编品牌和产品的官方中文名，也不为一个英文词把整条中文口播译成英文。
- 双语统一放在字幕带内、按同一音频时间对齐；需要双行时中文在上、英文在下，每种语言尽量单行。纯中文保持单行。英文用清楚的常规无衬线字形。静音素材里的界面英文不算英文口播。
- 验收核对英文有没有漏译、品牌名是否准确、双语行是否溢出、手机上是否读得清。

### 小字、注释与花字

- **默认不叠小字**：来源、产品名条、阶段摘要、制作标签、重复说明都不加。只有不解释就确实看不懂时，才加最短的注释并按对应口播出现。来源链接留在素材说明里；素材本身的真实界面文字不算新增注释。先删重复文字，再决定要不要解释。用户不要小备注时全片排查。
- 缺说明会让观众把历史画面误认成当年/当次的直接证据时，优先换源段或重排语境；必要署名和真实素材原有文字单独判断，不靠堆小字补救选材错误。
- 花字只承载关键词，按唯一口播的真实词级节点触发。先看落稳版式，再查冲击峰值、回弹和退场；以实际效果为准，不凭模板名称判断。029「放大震动」只是试用过的一种强调，不是每条、每个关键词必加；换文案或变速后重新校时。

### 从参考图拆样式

- 字形、直斜、字重、字号、字色、背景填充、中英文层级逐项核对。用户只借字体时，不连带继承样张的绿底或黑字；“不要填充色”指字幕底色透明，字本身不透明。字体名不确定就写近似判断，并查实际能加载的字体；英文是否斜体单独验收。先看真实底片上的长短句样片，再应用整条；已明确的选择不重复问。
- **按阅读完整性分组。** 列出不足 1 秒的字幕、被拆开的完整词组、长英文和附加解释，优先合并同一语义组，保留真实语音落点；不为凑显示时长让字幕跨进下一个观点。中文读得完不代表下方英文读得完，括号解释也算阅读负担。核对最后一条字幕的结束和工程尾帧，处理字幕超出总长、尾句没有停留的风险。
- **主字幕和素材自带字幕分开审。** 飞行、加工、装配等动作已能说明时，去掉无关原字幕；有效对话、必要姓名和来源按信息作用保留。裁切不留半行字，不破坏主动作或脸。原字幕和本人配音讲不同内容时不并排放；不拿另一句采访的口型冒充金句原话。找不到原话采访，就用本人转述配过程或环境画面，不伪造同步采访证据。

### 人像、素材与同步

- **形态、大小、位置是三个独立参数。** “竖长椭圆的尖角磨平”只修轮廓，保持竖长比例，不改成正圆；“这一处放右下”只改这一处。保留头发、脸、肩颈和必要手势，按主证据和双语字幕找空位；尺寸变化要有遮挡或信息层级的理由，不因换素材就忽大忽小。
- **看真实边缘。** 查上下端、左右弧线、裁切和圆角叠加，避免尖顶、尖底、断弧和露边。发现一处就枚举全片同类人像，在不同源时段和大小的实际合成里回查；先用一个代表片段验证修法，再批量修同一根因。
- **素材铺满后逐镜看得清、对得上。** 除覆盖和重复率外，检查实拍与截图比例、手机可读性、暗场/黑底标题卡、动作峰值和前中后帧。报道截图只承担确实要读的原文证据，不反复用密集段落代替制作过程；换入的实拍要证明当前讲述，不拿后来的飞行画面冒充早期平板/航模记录。
- **动效先解决观看任务。** 不默认用圆圈、箭头、通用图标解释人物经历；用户嫌简陋时先判断这一层是否需要。真实过程能说明就用实拍；确需动效，先在真实底片上确认信息层级、材质、构图和落稳样片，再做动作。换图标、加装饰不等于提升质感。
- **用户手调后按唯一口播重查同步。** 粗剪排序、删除、变速或用户手调之后，分别比较本人画中画与口播的成片起帧、源段起点、速度和结束，看是否有固定帧偏移。B-roll 可按语义提前进入，讲话人像的嘴形必须跟声。保护用户现有剪口，不只平移字幕、不按旧记录恢复整条；字幕、动效、音效、音乐结尾和总长成套核对。

## 3. 声音

- 动作感强的题材（机器人、功夫展示等）按[动作配乐专项](channels-action-audio.md)：急促、有短促起音的小提琴/弦乐，优先从常用配乐 ABC〔资料：视频号配乐库〕 选，三首都保留；旧弦乐候选池〔资料：视频号配乐库〕只用于扩选。其他题材按叙事情绪选曲。选曲试听流程见[视频号制作与局部返工 §5](channels-montage-review.md#5-选曲比较前置卡点单独验收)。
- 具体段落、BPM、混音量、降噪强度、音效数量和转场按本条视频决定，不照搬单片参数。
- 音效服务页面动作、切镜或语义重点：短扫过配移动，低频冲击配落点，机械点击配机构细节。同一音效可以复用，但不是每刀都炸一下；外语原声的重点段避免音效抢声。
- 先定曲风，再定截取段落，最后调混音。每次只改一个变量，用同一口播区间、同一设备和设备音量比较。
- 回读音乐片段增益、音乐轨自动压低量、原声/口播轨角色和淡入淡出。百分比按线性音量换算：再降 15% ≈ 当前增益再减约 1.41dB，而不是减 15dB 或凭空设成某个百分比。
- 参数正常、生成成功、音频存在都不等于听感通过。回听人声切口、喷麦、降噪失真、鼓点遮字和后半段音乐变化；无法实际回听就写明待试听。

## 4. 风格调整与竞品参考

新片或整套风格调整时，先找同平台、相近形态的真实视频号样本，选一个主参考，必要时补少量参考。记录原视频或可定位来源和时间段；只看封面或截图不能推断剪辑和声音，用户给的截图只支持静态版式参考。

| 对比项 | 必须看/听什么 | 如何变成修改 |
|---|---|---|
| 字体 | 字形、直斜、字重、字距、字号层级 | 不确定字体名就标近似判断，选渲染器支持的字体做同文对比 |
| 配色 | 标题、副标题、字幕、强调词各用什么色，背景与留白关系 | 写清每种颜色的角色；竞品花哨也不每层加色 |
| 动效与镜头 | 关键词落点、进出时长、镜头观看动作、动效与主体关系 | 用真实口播做 10–15 秒代表样片，检查完成态与峰值遮挡 |
| 配乐与音效 | 旋律、鼓点、密度、落点、人声与背景相对音量 | 同一口播片段试听；音乐节奏和音效冲击分开比 |
| 效果证据 | 用户明确评价；有真实后台时看停留、完播 | 没数据就标待验证，播放量或个人观感不能证明某种字体有效 |

单次优化至少记录：`竞品来源与时间段 → 可观察机制 → 当前问题 → 本次只改什么 → 同段样片/试听 → 用户或数据结果 → 保留/撤回/待验证`。不做未要求的自动监控，不为选型批量生成收费音乐。

待验证的候选（不是默认）：文案用动作/结果开场、接一个问题，用“第一套/另一套/你可以理解为”作结构路标，少堆连续性能数字和夸张断言；说话先试每秒 4.5–5.5 个汉字，每句一个重音，问句和机制切换处留自然停顿。竞品参考是作者另行记录的内部资料，不随本 Skill 提供。

## 5. 开工与交付验收

开工：

1. 假设观众零背景，写一句最可能的错误复述；事实、原声含义、演示与量产/使用条件之间不跳步。
2. 明确真实素材、新闻日期和引述上下文；“今天”跨日要重新核对音频和字幕。
3. 在真实底片上查字体、配色层级、手机可读性、动作峰值和安全区；截图只证明静帧。

交付前闭环：

- **素材**：每个语义段有对应画面，重复对象和最长停留时段符合本次要求；示意标识和来源对得上。
- **版式**：固定标题、单行注释和下方字幕分工清楚；逐段查长术语、英文、编号和进出边界。
- **时间**：只改画面时原声映射和总长不变；改过原声就重查受影响的声音、字幕和所有同步层。
- **声音**：口播、配乐、音效一起连续播放，查轻声句、音乐密集处、音效落点和结尾。局部试听或不含音效的电平诊断不算整条混音验收。换音乐或改音量后同时核对片段和轨道参数再试听；工具摘要和本地文件冲突时以当前工程和实际播放为准。选曲、混音、画面卡点、听感分别报告完成与否，没逐段对齐不叫已卡点。
- **状态**：用户看到的是已核对的时间线；文字写入、静帧验证、连续观看、听感验收、导出、发布分开报告，可编辑工程、已导出文件、已发布链接分别记录。只有相关验收做完才标通过；没回听就不说听感通过。
- **产物**：覆盖保存同用途的当前审看图，说明本轮实际改了什么、还有什么没完成；用户没要求导出就停在可编辑工程和预览。

复盘记录区分三种状态：用户已纠正且工程已修、只读检查新发现、待连续播放/回听。记了问题不等于修了工程；更新规则也不构成导出授权。

单条视频的题目、段落结构、编号、换镜间隔、镜头数、总长、曲目、增益/压低数值、注释字号/坐标、底条尺寸、人像比例和单片字幕配色都不作后续默认，见[视频号单片参数](cases/channels-samples.md)。
