# 剪辑与动效 Skill 调用地图

用途：按需选择制作工具与交接片段，也是 Lidali 可阅读的现有视频能力表；完整流程只在项目 Skill 维护。工具能力最近核对于 2026-10-21，插件或子 Skill 更新后以其当前说明为准。

## 1. 先选画面任务，再选工具

每个镜头只设一个主任务。先使用本条真实素材、唯一口播音频和当前工程，再决定是否需要额外生成。

| 画面任务 | 首选 | 何时调用 |
|---|---|---|
| 证明真实输入、操作、输出 | 真实录屏/截图 + 当前剪辑工程 | 有事实或能力需要证明时；动画不替代证据 |
| 不知道什么效果合适 | `bela-motion-director` | 分镜/动效选型时，先推荐少量方向与一个 demo |
| 口播需要个人化补画面 | `bela-broll` | 选段与素材设计时，分流人物、信息动画和视觉隐喻 |
| 想找已有镜头效果来做单个镜头 | `video-shotcraft` 单镜头模式 | 画面任务已明确、静态定版与动画实现之间 |
| 复用001–030文字动效或网站配置 | `bela-text-motion-library` | 已有编号/配置直接复用共用源码，不重新选型 |
| 一个对象连续变成下一个对象 | 用户指定的 OneTake Pro | 先读 [OneTake 工作流](onetake-workflow.md)，重点写清跨节点保留下来的对象 |
| 做短标题、数字、图表、路径或标注片段 | `motion-graphics`，或当前工程原生 MG | 主画面关键词和对应口播节点明确之后 |
| 真人底片上加信息卡、画中画 | `talking-head-recut`，或 ChatCut 口播 + MG | 已有底片，需要包装且不改变底片剪辑时 |
| 修界面展开、收起、跟随、弹簧与连续性 | `apple-design` + 已选制作工具 | 界面动效设计/实现/局部复核时；仅加载相关章节 |
| 实际剪口播、去重复、重排素材 | `video-use`，或 ChatCut `talking-head-guide` | 素材盘点、语音剪辑和母版合成时 |
| 修竖椭圆、完整录屏、身后字/抠图或场景音效 | [小红书精修](xhs-motion-audio.md) + 当前编辑器原生组件/可用本地辅助 | 小红书包装与返工；先验证最难的短区间，外部工具不可用不默认转付费生成 |

`Apple Design` 提供交互设计原则，`Video Shotcraft` 提供镜头配方，`onetake` 提供连续动效制作流程。HyperFrames、Remotion、GSAP 是实现层，ChatCut/剪映承担编辑母版。它们不需要每条视频都串联调用。

## 2. 画面制作交接

阶段、执行顺序和停止条件统一读取[唯一阶段表](../SKILL.md#唯一阶段表)，本地图只负责工具选择与片段交接。仅为需要新增或替换画面的节点填写下表；不为普通错字修正重新做分镜。

| 时间窗/触发词 | 观看问题 | 真实素材/示意 | 主路线与版本 | 完成态与承接对象 | 输出/可编辑性 | 接回位置与声音 |
|---|---|---|---|---|---|---|
| 真实词级节点；无音频则待校时 | 这段帮助观众看懂什么 | 路径及来源 | 一个主路线、必要辅助 | 关键对象如何进场、停留、退出 | 原生组件或渲染片段 | 母版轨道、覆盖时窗、原声与必要 SFX |

已有定版、模式与当前工程直接沿用。效果已明确时直接制作，未定时才用 bela-motion-director 选型；指定文字动效编号/配置直接复用。字幕、进度条与声音从母版取时间，必要的工程接入使用下方对应任务 Skill。未授权的生成、导出或发布不由工具地图自动放行。

### ChatCut 工程保护

2026-11-22 从小红书分支移来，两个平台用 ChatCut 时都适用；不用 ChatCut 的工程不读。

- 剪动说话、停顿、重说或转录选择时，用当前 ChatCut 的 Script 工作流；改画面时不拆改口播。每个声音切口回听前后完整句，保留字头、尾音和自然气口。
- 用户自己分割、替换或移动后，先回读最新时间线再局部接续。替换前景时同时核对模糊背景、旧标题、头像和音轨；删掉旧背景残留或恢复误删的头像属于本次相关修复，但不重置用户已剪的段落。
- 局部编辑先明确不变量：稳定的工程/时间线/轨道 ID、目标帧区间、源区间、总长、字幕和声音。工具可能随速度变化重算时长；需要保持窗口时同时显式指定 `durationInFrames` 和稳定的 `trackId`，并回读实际起止和轨道。
- 分清源时间单位和时间线单位。取帧号前探测源文件的真实 fps，导入元数据或旧记录不能当本地源属性。换源资产按工具允许的操作完成，避免复制项留下互相冲突的源偏移字段。
- 已有 MG 以当前工具里的资产/实例为渲染权威，过期的本地 JSX 只作历史。改代码前读 revision，按当前工具契约内联提交；只改本次相关逻辑，保持可编辑分层。
- 同一浏览器会话里的渲染/预览依次执行，忙碌时按返回状态等待，不重复并发提交。抽帧成组、有目的地做。缺层时先核对轨道、范围、透明度、蒙版和媒体，再判断加载/缓存，必要时用相邻帧或实际播放复核。
- 导入或替换媒体后，分别核对资产登记、时间线引用和用户当前编辑器的实际加载；工具侧能渲染不代表用户当前页面看得见。用户反馈看不到时，先查当前页面的待关联状态和缓存来源，按正式导入/重连路径恢复同一资产，不先重复添加片段；恢复后在用户当前页面确认。
- 重剪先用 Script 明确保留/删除的语义；用户已经删句时沿用删减结果，不恢复旧句。取当前音频的源段映射，同步嘴型视频、人像、字幕、案例、名称、音效、导航和总结。除了实例起止，还要查动画内部延迟、前景抠图的源帧/速度、进出场、词级进度和总长；部分轨道已前移时逐层比对，不能再全选一律减同一个秒数。
- Hosted ChatCut 在指定一条 speech track 后仍可能返回多条已转写的轨道。按当前工具契约限定提交范围，预览时核对只改了目标轨，不把含 B-roll 的整份返回文稿原样提交。重排/量化后回读实际源段；旧秒点和旧实例 ID 标为已替代，不再用于后半段返工。
- ChatCut 原生字幕卡的单行修复：回读用户当前文字和单卡覆盖 → 清理误追加的旧句、显式换行和旧分段 → 在安全区内调整字幕框 → 语义拆卡 → 看当前渲染。只有短名称/身份句仍被错误折行时，才用同字体、同字号、同粉底的单行组件；替换原生卡时同时隐藏原卡的文字和底条，名称、显示区间和组件位置绑定当前音频。`maxLines=1`、卡片诊断单行和真实合成单行是三项独立证据，只有最后一项算数。
