# 小红书人像、录屏、动效与音效精修

适用于本人小红书的人像（小框或竖椭圆）、身后花字、网站/工具录屏、闪现/转场和交互音效。人像形式、音效色板等默认做法见[样式卡](xhs-style-card.md)。由[小红书分支](xhs-editing-review.md)按问题进入；口播剪口与混音的共同底线仍在[共用规则](editing-rules.md)。这里补制作步骤和验收方法，不另设平台速度、字幕皮肤或全片固定坐标。

<a id="1-竖椭圆头像先看人再定蒙版"></a>
## 1. 人像（小框/竖椭圆）：先看人，再定取景

- 小框和竖椭圆用同一套检查：先截一张人像静帧给用户确认大小、头顶留白和肩膀露出多少，再铺整条。小框规格见[样式卡](xhs-style-card.md#1-开剪前要问清的两件事)。
- 长视频的人像不交给 HyperFrames 一类网页渲染器解码（会重复帧、口型对不上）：网页层只出透明图形，人像和原声用 ffmpeg 逐帧合成，合成后抽查人像帧与原片一致。
- 区分源视频框、蒙版框和实际头肩轮廓。保持人物原比例，用连续光滑的椭圆路径或相当于 `ellipse(50% 50%)` 的蒙版；只改圆角半径不能证明已得到椭圆，不能出现顶部双尖角、削平、拉长的脸。
- 先在源片里找头部最高、最低、偏转和手势最明显的帧，再调蒙版与取景。蒙版内保留完整头发、头顶可见空白、脖子、双肩及部分上身；不能只用正面静帧定裁切。头顶留白随实际动作决定，不把本片尺寸和 `object-position` 写成全片默认。
- 先放大主证据，再给小头像找非关键空位。检查新录屏加入后的层位；隐藏只作用于需要让位的区间，回到真人时不要留下第二个小头像。大人像与小头像切换要有叙事理由。
- 真人小头像必须使用正在说这句口播的源段和速度。每个片段按 `源时间 = 源入点 +（当前时间线时间 − 片段起点）× 播放速度` 计算；用实际源帧率换算帧号，不拿时间线帧号直接索引源片。粗剪、变速、用户删句后重新映射，不能只移动头像外框。
- 验收：在实际合成里连续看正脸、最高/最低头位、源段切口、显隐和恢复点。头发不顶边、脸不变形、肩颈存在、没有尖角/重复头像，嘴型与原声同步；抽帧只负责构图，不代替嘴型连续性检查。

## 2. 录屏：完整展示结构，压缩等待时间

- 开剪先选观看任务：**整体布局**、**真实操作**或**局部效果**。整体布局默认完整窗口；真实操作至少完整保留输入、按钮、反馈及结果的相关关系；局部效果保留完整的目标卡片、整行文字和动作终态。不能因为某个裁片漂亮就更换这句话的证明对象。
- “撑开/铺满”先解释为保持原比例、尽量使用可用宽度。横向录屏不默认纵向 `cover`；安全区也不等于给整个录屏四边套统一内缩。平台遮挡保护关键证据，背景与无关边缘可以延伸到边界；为保住结构而上下留白是合理的。
- 放大前分清录屏外围空白和页面内部留白：可以去掉无用外框、浏览器栏或播放器外侧空白；页面中的卡片间距、标题和信息关系不能一并误裁。脱敏时优先在已选实录上局部遮挡，保留原有操作链、速度与源段。遮挡跟着滚动和变形走，在最大展开、进退场和回顾复用处复查。联系方式等须隐藏的信息应达到不可辨读，兼顾操作控件和反馈可见。遮挡与关键操作冲突时，优先补录同一操作的干净版本。素材仍小则先减少装饰或同屏数量、移动头像，必要时先全景后局部。
- 定好取景后，至少查片段开头、滚动经过的上下边、最长一行、最大展开、完整结果和退场。**人为取景切断需要阅读的行、文字顶着裁切边、按钮/响应关系消失，都不通过。** 浏览器原生滚动经过边缘时的短暂截行不等于裁切错误，但不能停在这里让观众读半行；阅读时让目标整行/卡片进入窗口并停留。快速目录扫览不要求读每张小卡，前后仍须有可辨认的整体/落稳画面。
- “播放完整”保护的是操作链和句子/结果的完整，不是原样保留几十秒等待。保留开始动作和最终反馈；中间生成、加载、重复敲命令可用加速或跳切压缩。接点放在动作或状态边界，不切断 AI 回复句子、不突然换成无关结果，也不把压缩后时长冒充真实耗时。
- 字体、Icon、图表、目录总览和复制发给 AI 分别取对应素材。说“很多”先给真实汇总/翻阅，说某一项再拎出该项；复制编号时必须看得到真实复制及输入过程，调参录屏不能代替复制。相邻及前后段查源区间，重复出现必须带来新输入/状态/结果。
- 录屏发糊先查源分辨率、导入尺寸、取景放大倍数、有效帧率、预览质量和实际输出规格，不凭感觉归因于降速。保留可用的全分辨率源，不反复导入压缩预览；局部放大超过源细节能力时换源或重录，锐化修不回丢失的字。

## 3. 身后花字与抠图：同源、同速、同一可见时窗

- 层次明确为底片 → 花字 → 透明前景人物；不能靠把字盖在脸上或糊一层背景冒充“在身体后面”。先锁定实际字形与文字交叠区域，优先复用本片确认的黑白花字风格，不加无用的角标和小字。
- 抠图从**当前口播源映射**取帧，底片、前景和花字共享时钟。分别核对素材外部起止与代码内部延迟；需要提前预载时预载层保持不可见。花字实际显示的每一帧都有同帧前景遮挡，两者在下一句前一起退出。删句后旧透明序列不能只平移后继续用。
- 先对头发、肩部、手指/手势最难的短区间试抠，再铺这一段。按头发和手势调整软边、孔洞与时间稳定性；分别在浅色、深色诊断底和最终底片上看，避免漏抠、背景残块、光边、边缘闪烁。诊断底不进入成片。
- 可只处理文字与人物相交的区域，减少透明素材负担；先检验蒙版/透明通道在当前编辑器是否真正被保留。可选用本地分割、逐帧蒙版或少量人工关键帧修边；把特效/蒙版作为辅助层接回，保留母版口播和原生文字的可编辑性。
- 卡顿分别排查真实丢帧、重复源帧、帧率/速度映射、逐帧序列读取、过大图集与解码/内存压力。只预载需要的邻近素材，缩小处理区域或采用当前编辑器支持的透明素材/蒙版；不得复制静止脸帧撑时长、拉长低帧率片段或靠溶解掩盖错位。
- 验收：连续播放入场至退场，重点看眨眼、张嘴、转头、手经过文字和图集/源片接缝。当前编辑器与同母版短片段分别核对：只有编辑器预览慢就处理预览/加载，输出也停住就修源时钟或素材。静帧抠得好、代码通过、透明棋盘格正常都不等于动态通过。

## 4. 花字、闪现与转场：动作先成立，再配声音

- 同一件事跨镜头时，先写清 `口播触发词 → 上一镜观众在看什么 → 下一镜接着看到哪个对象或操作结果 → 在哪里读完`。用同一对象的位置、比例或运动方向承接，例如工具截图展开为同一个真实页面。用现有镜头表挑一段最难的交接，连看上一镜、转入和结果落稳，确认观众能跟住再铺开；换到独立场景且焦点明确时可直接切。换布局先排好完成态，不能用强闪白或长叠化遮盖上下跳、半行字和错误取景。
- “闪现”是短促揭示关键对象：出现要快，随后给足识别和阅读时间；不等于连续白闪、抽帧、每个字随机翻转。艺术字只强调当前重点，字形与位置落稳后保持可读，不持续抖动。
- 按内容选短推近、遮罩揭示、卡片替换、翻页、轻扫或直接切。翻页要有页面/卡片的可见翻动；直接切换可以配轻扫声，但不因此声称加了翻页效果。同段机制可以复用，相邻同方向同幅度的重复要有理由，不能每个镜头都套相同弹簧。
- 运动以当前口播为基准，视觉入场峰值、音效重音和讲到关键词的时刻对应。连续检查入场、最大形变、落稳、退出和相邻镜头。

## 5. 音效：按语义选，手机上清楚听得见

默认按[样式卡的音效色板](xhs-style-card.md#4-音效色板)给每类画面动作配不同的声音，不用同一种声音贯穿全片。先读当前口播、视觉动作和本片已确认风格，再选声音；不能只看文件名/音效库描述或按时间间隔填声音。干净、短促、清脆、短尾音作为普通界面演示的试选方向，最终取舍以本片试听为准；不把本片低沉冲击、曲目或固定 dB 迁成通用默认。

| 实际画面/任务 | 试选声音与同步方式 | 不通过的情况 |
|---|---|---|
| 输入框逐字输入 | 短、干净的键盘敲击；按字符/短词出现的真实节点铺，不是一直播放不分停顿的循环 | 有字无声、停打后还响、鼠标声代替键盘、机械切片截断敲击尾音 |
| 发送、复制、按钮确认 | 批量加鼠标声前，在当前合成中逐点确认点击标记、按钮按下或可归因的界面变化，按实际帧记录并对齐。只有反馈可见时，可按需配短确认音 | 仅移动、悬停或滚动时猜测点击，连续拖动当成多次点击，改裁剪或速度后沿用旧落点，重复提示盖住口播 |
| 花字/小卡片弹出 | 轻 pop 或短促敲击，和出现/落位对应 | 拖长的闷响、尖锐到刺耳、每个字幕字都配声 |
| 页面翻动、卡片切换 | 短纸张翻动/摩擦或轻空气扫过，按可见动作选 | 没翻页却硬配厚重翻书声、相邻镜头同一种长 whoosh |
| 数字翻牌、滚动、冲击放大 | 克制的机械卡扣或短低频强调，保留数字/结果阅读 | 长滚鼓淹没数值、普通 UI 连续重 boom |

执行与验收：

1. 在当前母版里保留独立音效轨。先试听并定位有效起音、重音和可用尾音，再决定取段和淡化。放入后回读片段的源入点、实际时长和淡化，确认实际播放范围仍包含攻击点与可用尾音，再核对重音是否落在可见动作上。原库有锚点时，裁切后按新入点换算；尾音与下一声冲突时按听感留尾、缩尾或换短音源。
2. 先调到**手机正常播放音量下可辨识**，再检查口播清晰度。音效可以短暂突出，但不让字头、数字和句尾被遮住；“别盖人声”不能执行成把所有音效压到几乎无声。调整前读回素材自身电平、片段增益、轨道静音/压低和输出设置，避免多层重复衰减。
3. 用含完整口播的同一小段比较音效开/关及两个接近的候选；分别查开头打字、最密集转场和最大冲击，随后连续听整段。既听单个声音，也听声音之间是否机械重复、突兀或发闷。波形、峰值或零削波只能作技术检查，不能代替听感。
4. 用户说“在当前基础上提高 50%”时，按当前线性增益乘 `1.5`，相当于约 `+3.52 dB`；连续调整按最新值累乘。只调整指定音效范围，不顺带提高口播/BGM，也不把曾经多次追音量的单片结果写成固定默认。
5. 无法实际听音时，先利用当前可用能力排查静音、增益、锚点和切片错误，并从同一母版交付短音频试听；明确尚未完成听感验收。不得把“增益已写入”说成“清脆适配、别人听得清”。短音频自检按当前工具支持执行，不等于整片导出或发布。

## 6. 外部/付费工具不可用时继续解决

- 先判断缺的是内容/证据、工具功能，还是试听/观察能力。先盘点本条已有源素材、当前编辑器能力、可用本地库和模型；普通裁切、时钟映射、蒙版、字形动画、界面提示声不默认需要付费生成，也不把“没有某个插件”当作用户必须自己修的结论。
- 在已授权范围内，优先调整原生编辑器组件；不足时用代码制作可编辑动效、局部蒙版/透明辅助素材、波形诊断或程序化短提示声。先做最小难点验证，确认能接回母版并看到/听到结果后再扩展。使用当前可用实现，不把某个模型或“本地一定能抠干净”写成能力保证。
- 保留用户指定的主编辑器和可编辑母版。本地辅助素材不是重新压缩、合成整条视频的理由；具体导入、生成、网络和调用限制以当前工具契约为准。权限/自动审核拒绝不能靠换路径绕过，工具不可用与权限拒绝要区分。
- 缺真实证据不能用自制 UI 冒充；需要的场景示意经授权可制作并说明性质。试过适用路线仍缺关键原件、实际观察/听音能力或授权时，给出已做的定位、可用替代与唯一必要缺口，不虚报完成，也不反复换无关素材碰运气。

## 7. 这轮制作如何通过

沿用现有镜头表记录：`当前源入出点/速度 → 受影响的层 → 起止和内部触发 → 手机构图 → 连续播放 → 听感 → 未验证项`。

- 头像、录屏或抠图首次出现时，先验证一个最难的代表片段；这是助手先自检的执行门，不是每个局部修正都向用户要批准。用户明确要求先看时再按其确认顺序制作。
- 用户删句/加新素材后，以最新口播和手调为准，成套重算字幕、头像源帧、花字/透明前景、B-roll、音效和结尾；原素材、内部时钟和取景一起查，不能只把轨道看齐。清掉旧标题、旧背景、已结束的头像与无声尾巴。
- 抽帧验证比例/遮挡，连续播放验证动作/卡顿，实际回听验证吞字/气口/音色/混音。若已授权生成最终文件，还要检查最终文件；工程预览、短音频、成片与平台预览分别报告证据，没做的检查不能写通过。
