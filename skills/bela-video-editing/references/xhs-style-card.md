# 小红书现行样式卡

Lidali 于 2026-11-22 以《1123 Git 和 GitHub》9:16 成片确认的小红书样式。新片开剪时先读这张卡，再按[小红书分支](xhs-editing-review.md)做粗剪、制作和验收。卡里写的是默认做法；本次简报或用户当下的要求优先，单片秒点和坐标仍留在各片记录里。

## 1. 开剪前要问清的两件事

- **目标时长。** 没有默认秒数。用户没说时，开剪前问一句“这条大概剪到多少秒？”，再按这个长度删重复和铺垫。
- **人像形式。** 由视频类型决定，不固定大小和角落。用户没说、类型也看不出来时，先问。

| 视频类型 | 人像默认 | 说明 |
|---|---|---|
| 教程、流程讲解、B-roll 为主 | 小框陪伴，素材占主画面 | 1123 的确认规格：4:5 圆角框 360×450（1080×1920 母版），圆角 20，淡渐变边框；从原片上沿 y≈40 起裁，露出头顶、脖子和双肩；放左下或右下，离两边至少 96px，按段落交替；全片保持同一大小，不在大头和小框之间来回切 |
| 日常唠嗑、观点分享、真人为主 | 大头像或真人全画面 | 证据和花字围绕人安排，可用身后花字 |
| 两者混合 | 按段落选 | 切换要有叙事理由，并在 30 秒样片里让用户确认切换方式 |

竖椭圆小头像仍是可选形式，制作方法见[人像精修](xhs-motion-audio.md#1-竖椭圆头像先看人再定蒙版)。人像构图先截一张静帧给用户确认，再铺整条。

## 2. 画面

- **底图（小框形式）：** 用静态暗色渐变，黑色系或很深的蓝，1123 用的是“暖夜”。先给 4–6 张静帧让用户选。备选拼图和正式底图分开保存，换底图后先看一帧真实合成。不用本人视频的虚化画面当背景，因为它在动、会喧宾夺主。
- **字幕：** 按[小红书字幕](xhs-subtitles.md)，粉底黑字（得意黑）。人像在下方小框时，字幕上移到素材和人像框之间。
- **导航：** 默认 A。顶部一排短标签，每段一个，下方是等宽分段进度条：当前段粉色，已讲完白色，没讲到的半透明，底下加半透明蒙层保证看得清。开头用一页结构总览说明本期讲几件事，每次换章插一张过渡卡（编号＋完整章节名，约 1.2 秒）。短片或没有章节的内容可以不加。用户点名 ChatCut 的 bela-jindutiao 皮肤时，按那个 Skill 做。
- **花字分场景使用，不出现只有字的页面：**
  - 真人大画面时，关键词可以做成身后沉浸花字：人物抠出，字在人身后，带动效。做法见[身后花字与抠图](xhs-motion-audio.md#3-身后花字与抠图同源同速同一可见时窗)。
  - 手绘纸面或 B-roll 场景里，字写进画面，跟着人物、物件一起出现，不另做一张纯字卡。
  - 讲到有图可看、有视频可放的地方，必须出图或视频，字只作补充。

## 3. B-roll 素材：按顺序找

1. **自己已有的材料：** 课件、直播课、图文、录屏、主页置顶等，按口播逐句对上。1123 用的是直播课课件截图加真实 GitHub 录屏。
2. **没有现成材料时：** 去网上找真实页面和官方素材，或者自己录屏。外链、二维码、用户名、安装命令按发布风险处理掉。
3. **还缺的部分：** 自己做小动效或小视频（HyperFrames / Remotion 等），或者做手绘纸面。手绘纸面里的人物用火柴人（小黑人），它能做挠头、摊手、晕倒、躺平这些动作。
4. **贝拉 IP：** 在开场、转场、解释页、结尾等合适的位置可以出现，按贝拉 IP 风格卡和 `bela-ip-pic` 制作。手绘纸面内部仍用火柴人，真实录屏和证据截图里不画人物。

开剪前先做一张“口播句子 → 素材来源 → 这一屏要让人看懂什么”的对应表。对不上内容的地方才做动效，不用炫酷效果代替内容。

截图和录屏至少保留能认出页面用途的完整区域，只为去掉敏感信息才裁。高光框和圈要叠在原图上逐个核对位置。

## 4. 音效色板

不用同一种声音贯穿全片。按画面动作对应：

| 画面动作 | 声音 |
|---|---|
| 纸面、页面进场 | 翻页（两种交替） |
| 课件或截图进场 | 闪入 / 轻扫，交替 |
| 马克笔划线 / 手绘圈 | 笔划声 / 贴纸“啵” |
| 打勾 / 打叉 | 叮 / 短促错误音 |
| 物件弹出 / 落下 | 轻 pop / 落地声 |
| 箭头画出 | 刷 |
| 换章过渡卡 | 呼一下＋叮 |
| 点击按钮或封面 | 鼠标点击 |
| 拍照、记录 | 快门 |
| 退回、撤销 | 倒带 |
| 打字、下指令 | 键盘声 |
| 点赞收藏、结果闪亮 | 闪光 |

两个音效之间至少隔 0.14 秒，同一种至少隔 0.4 秒，冲突时留更重要的那个。音效整体比人声低约 6 dB。试听和验收方法见[音效精修](xhs-motion-audio.md#5-音效按语义选手机上清楚听得见)。

## 5. 制作与验收

- **先做 30 秒样片。** 样片要覆盖本条会出现的所有画面类型：人像、底图、字幕、导航与换章、课件或录屏、手绘或动效、音效。用户确认后再铺整条。
- **长视频人像不进网页渲染器。** HyperFrames 一类工具长时间解码视频会重复帧，人像卡住、口型对不上。网页层只渲染透明图形（导航、字幕、B-roll、音效），人像和原声用 ffmpeg 逐帧合成。
- **铺整条时先出低帧率草稿抽帧查版式**，确认后再出正式渲染。
- **交付前做挤占排查：** 全片每 1.5 秒抽一帧拼成总览。每个手绘页还要在元素最全的那一刻单独看，检查文字出边和图形互相压。文字溢出检查只管文字是否出边，查不出图形之间的重叠。
- **删掉一段口播后，** 检查剪点前后 2 秒。落在删除区间里的动画时间点会叠到剪点上，例如过渡卡停住不走。
