# 新闻解释视频：观众理解与剪辑接续

适用于 Lidali 本人小红书/视频号的新闻解释、真人热点、素材可信度、画中画、音乐起势和离线接续。这里只存决策方法；项目选择和实际制作记录留在各条工程。平台的字幕、标题、安全区、倍速和换镜节奏按各自分支，本文不另设。案例来源：马斯克赠股剪辑复盘〔资料：单片案例资料〕（原工程按视频号制作）。

## 现行状态先对齐

接续只认一份当前状态：交付视频、实际母版/源工程、唯一口播、字幕时间基准、当前标题、音乐和本轮锁定范围。brief 是当前摘要，不在顶部一层层叠加互相冲突的“最新”；被替代的稿标为历史，并链接实际时间线或当前审片说明。

同一路径的文件可能已经换了内容，按内容指纹或工程 revision 判断缓存是否失效，不只看文件名。用户后来改了可用人物、措辞或素材范围时，同时检查口播、字幕、主标题、素材内的新闻条、人物镜头和角标；删除后重新检查主语、地名、指代和气口。删除范围只限本条授权，不变成全账号的永久禁令。

## 声音先解决实际问题

- 底噪、房间回响、重复试讲/口误、音量和速度分开诊断；空间感重不等于要再做一轮普通降噪。
- 先拿同一完整语义段做处理前后、响度相近的试听，再决定要不要应用到全段。保留气口、字头尾和本人音色。
- 全片转写可能自动省略重复的起句。用户指出卡顿或重复时，查有重叠的短段、波形并实际回听；ASR 只是辅助证据，全片文字干净不代表声音干净。
- 唯一音频锁定后再精确对齐。只换画面时保持已确认的音频；适用时比较源音频或最终音轨数据，说明实际变动范围。
- **声音能力要有可听证据。** 讲解环境音、配乐生成或角色对白时，选对应能力、带真实原声的源段，留出不被本人讲解和 BGM 盖住的试听窗口；静音播放字幕和有声画面证明不了声音能力。只有本次授权允许调整口播或总长时才插入/延长，保留前后完整语义，并按母版重校后面各层；只换画面时不擅自暂停或重排口播。原片没有音轨或还没实际回听时标明缺口，不用后配音效冒充原生实录。
- 用户说“听不到”时，先区分文件里有没有声音、播放入口能不能用、设备/音量能不能听到；定位之前不反复叠增益或降噪。
- 能解码、ASR 一致、响度正常，都证明不了实际听感或播放器可听。没做听觉验收就如实交给本人试听。

## 把“看懂”落实到画面

- 先写出观众应该理解的一句话关系：谁发起、谁处理、发生了什么、结果去哪；示意要直接展示因果或状态变化，而不只是对象的外壳。
- 已确认的比例、配色、大小和材质先锁定。用户说不直观时，优先修关系、方向、对照和关键动作，不自动换整套风格。
- 熟悉的物体按真实高宽比检查，不为填满横框把手机压宽。先在最终竖屏素材槽和手机观看尺寸下看主体够不够大，再追表面细节。
- 讲抽象的请求/回复时可以用无字双色气泡；讲实际工具结果时用真实界面和真实文字。案例里的空白气泡不推广到操作教程。
- 静态定版、可动分层和工程引用指向同一版。材质换成确认的位图后，不再运行旧的矢量生成器把它覆盖；分层遮罩和最终落稳画面都要检查。
- 主画面文字逐项问“删掉会不会误解”。必要条件、数值定义、来源、新闻信息和版权保留；重复口播的字、对象一看就懂的标签和装饰小字删掉。来源记在内部清单，不代表可以删掉必须展示的署名。

## 语义同步与退出

按词级时间或人工语义节点入场，但一个完整的数值、单位或术语整体出现，不机械拆成可能被误读的中间结果。比如表达小数读数时，不为逐字卡点先显示另一个整数；不是真实计算过程的数值可以整体亮出，或用不暴露错误读数的方式揭示。

数字带统计口径：年平均、实时读数、温差不能互换。温度计的刻度、液柱、指示点和数字从同一个数值映射，而不只是让数字“对上”。

每个补充镜头标出进入、完成、退出和接回的对象。新动效只覆盖它承担的语义，下一句讲别的机制时及时接回。用户说“原始画面”而实拍和示意同时存在时，从时间段或已指认的素材定位；仍不唯一且会改变结果，就问清楚，不把猜测写成确认。

## 配乐与交付

音乐先定叙事职责，再选曲和段落：新闻推进、科技快讯、悬疑、抒情是不同需求。用户要其他选项时，用同一段口播、接近的响度和相同的人声压低条件给短试听，选中后再换整条。先核对来源和用途许可，不默认付费生成。

试听和最终接入来自同一个可编辑母版、同一种混音实现：先在当前工程里落地，再截取含完整句子的请求时长试听。独立的本地处理只能明确作为比较稿，不说成侧链、淡化或音量曲线已经写进编辑器。用户换曲或手调后，先读当前资产和音轨再改；按工具真实的触发方式区分“片段重叠压低”和“语音信号侧链”，前者不会识别句内停顿。

交付核对实际文件、受影响的切点和后半段。图片证明不了节奏，波形证明不了听感；已出片、本人终审、发布分开写。本地源工程不叫 ChatCut 工程，本地路径不叫外网地址。

播放器可能缓存同一路径的旧视频，重新载入前核对正在看的文件。用户同时在操作时，不反复抢焦点、关闭或改其播放位置，优先给最新的可点击链接。用户要“视频地址”时直接给当前可用的链接。

## 不作为后续默认的内容

案例里的 BPM、曲目、源段偏移、手机型号、数值、配色和人物排除范围都不固化为默认。速度按各平台分支，视频号的 1.2× 不用于小红书；视觉变化频率按[共用的每 3–5 秒有效变化](editing-rules.md#观看节奏与口播切口)。已确认的标题规范服从项目入口；某个字形难读时检查实际渲染并记录本条修正，临时换的字体不扩成全局默认。

## 真人热点：从观看任务决定素材

开剪前先回答三个问题：观众先认出谁/什么事，当前画面证明什么，下一镜增加什么信息。热点口播保留本人的分享、疑问和适量玩笑，不把查证资料直接念成新闻；开头和正文之间补足真实的因果关系，不用剪辑冲击代替解释。

- **先找真实动态，再补示意。** 说人物时优先给认得出的真人镜头；说操作时给真实过程；说承诺或条件时给原文证据。相关动态不够时才考虑截图聚焦或少量示意，不因动画 Skill 可用就先批量生图。
- **写清画面的证明范围。** 素材表加`直接证据/历史背景/演示/示意`以及日期、来源和可用源段。历史发布会只能帮观众认人，其他活动不能暗示是本次赠股仪式，承诺不能剪成已经交付。必要说明不能全藏在内部清单；删掉小字会误认时，优先换素材或明确语境，再保留最短的必要标识。
- **有效变化看内容，不看片段数。** 对照源区间、可见人物、动作和景别查重；换裁切、颜色、字体，或反复播放同一个发射镜头，都不算新增证据。每镜承担一个辨认、证明、过程或结果任务；只作背景的素材不充当因果证据。
- **冲突来自事实与预期。** 例如“作出承诺 → 分配机制 → 兑现条件”，用对应证据形成对照；没有冲突证据时，不靠大问号、夸张表情和动画小人制造冲突。转场按相邻镜头的关系选，硬切可以是主要手段；叠化只用在需要连续、时间流逝等语义的地方，不整片统一渐显。
- **确认静态材质不等于确认整条应用。** 新风格先看最终画幅里的代表完成态；需要动作时，再用一个短段验证动作、口播、字体和真实素材的衔接。用户后来否定了拼贴，就更新当前方向，不拿早先的“质感可以”继续批量套用。生成长时间没结果时报告实际状态，在授权范围内换更小、可编辑、可核验的替代方案；等待生成不算任务推进。

标题写清人物、动作、对象和必要条件，区分“承诺/计划/已落实”。用户要看网上标题时，核对实际报道和原始表述，取信息结构，不照抄情绪化断言或未经验证的金额。顶部固定标题和逐句字幕的分工按平台执行；视频号的固定双行模板不默认搬到小红书。

## 真人与证据同屏：先给主信息空间

- 先按手机观看尺寸放大主证据，再把人像放进每镜的空位；小红书小头像按[竖椭圆肩颈构图](xhs-editing-review.md#小红书小头像竖椭圆)，视频号按本条确认的形态，不为给头像留槽而缩小证据。用户要求全程素材覆盖时检查整条覆盖，不在个人判断或收尾处擅自回到大头特写；没有这个要求时仍可以按叙事回到真人。
- 保持源比例：`contain` 保证完整读取，`cover` 要确认被裁掉的内容不承担信息。画面太小时先裁无关背景、调布局，再缩放；网页、人物和字形不拉伸填满。多人、操作界面和长截图分别取景，不机械套同一种裁切。
- 逐镜检查头像、标题、字幕和平台 UI 的叠加，保护脸、操作目标、数字、条件和结论；开头位置没遮挡不代表后段也安全。空白过多时压紧信息关系，不用放大头像或堆装饰来补空。
- 制作标签、重复口播的小字和装饰性问号删掉；必要条件、真实性说明和必须的署名不在“不要小字”的批量删除范围里。字幕皮肤和安全区按当前平台专项。

## 配乐起势与离线重连

- “振奋、渐进”先翻译成可以试听的时间要求：开头何时有清楚的节奏，哪里提情绪，哪句要退让。按铺垫、疑问、例证、冲突与收束这些真实口播节点安排渐强/渐弱，解释和轻声句退让，不把每个短停顿都做成音量突升。看整段的强度曲线，不凭“励志/健身”这类曲风标签选曲。需要快起势时，先从原曲里找能自然起步的强段，必要时才缩短前奏或局部变速，口播速度保持不变。
- 换曲或改起点后，用同一段真实口播试听开头、起势接点和密集讲话处；检查拍点衔接、变速音质、峰值余量和结尾。片段增益和轨道 ducking 分别回读；设了压低不等于听感通过，人声字头字尾仍要清楚。
- 本地文件存在、编辑器能解码、云端已上传是三种不同状态。用户报离线时，先定位其正在看的工程和离线资产，核对素材名、资产 ID、本地路径和可用状态；助手另一个页面加载正常，不能用来否定用户的反馈。
- 保留重连清单和原文件，优先把原资产重连上，避免同名重导改变引用和源段。给用户可点击的文件夹路径和对应文件名，而不只是说“去找素材”；按当前工具支持的方式关联，不绕过导入边界。重连后看受影响区间的真实合成，核对裁切、时长和音频没变。案例里的临时文件夹、30 个文件和资产 ID 不是跨片模板。

## 对抗检查：尝试推翻“已经改好”

以下反例按当前题材选用，并执行[共用整条复核](editing-rules.md#整条复核与同类问题排查)；局部修改也要做全片同类问题排查。发现失败先修根因，不追加一套包装。

| 反例 | 判定与最小修法 |
|---|---|
| 把新加的问号和花字关掉，画面里还有承诺与兑现的对照吗？ | 没有就补机制/条件的证据，不再加装饰 |
| 每段都是新文件，却仍是同一个发射或同场表情？ | 查源区间和可见动作，换实际内容，不按文件数验收 |
| 片头出现马斯克，观众会以为是他宣布赠股的现场吗？ | 核对年代语境，换镜头或标明是资料画面；不伪造口型和原声 |
| 静态拼贴好看，接回真人新闻后却像广告贴片？ | 整体衔接没通过，退回真实素材路线；静态认可不等于整片通过 |
| 手机上证据仍很小，大片背景只是给头像和标题占位？ | 放大主信息、裁背景，逐镜给头像找空位；证据可读性优先 |
| 开头头像不挡字，后面却正好挡住孩子的脸或审批条件？ | 查后段最拥挤的状态和换镜边界，改那一镜的布局 |
| 曲子后半段很燃，前几秒却还在等前奏？ | 试听成片起点，重选音乐源段；整曲标签不是起势证据 |
| 讲“风声、配乐、角色台词”，却一直是本人讲解盖住演示，或源片被静音？ | 画面证明不了声音；按授权留出真实原声窗口，回听前后衔接并重校受影响层，没听就标待验收 |
| 音乐参数很低，讲话快时仍听不清？ | 实际听这一句，分别修 gain、ducking 和频段/段落选择；没听就标待验收 |
| 一处能播放，就说全部离线已修复、云端也正常？ | 逐一核对报错的资产和受影响的段，只报告实际验证的范围 |
| 这条的参数顺手，下条小红书也套视频号的 1.2×、绿底双行标题？ | 平台分支错了；回到小红书现行的字幕、安全区和本条速度要求 |
