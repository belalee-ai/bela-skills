# 标题来源与视觉选项

用户于 2026-09-15 补充：可以建议其他视觉参考与标题选择；标题结合 DBS title、网上热点资讯逻辑，以及最初两张竞品截图的内容主题结构。

## 三种标题来源如何协作

### 1. 内容与热点决定讲什么

从本期材料先提取：谁、发生什么、什么变化、与此前的差别、谁受影响、哪一个具体画面能够证明或解释。

- 素材足够且只是重排已定文字时，无需为了“热点”进行无关搜索。
- 用户要求结合最新热点，或新拟标题引入时效事实时，使用 `agent-reach` 的适用网页/搜索路由，并用内置 Web 查一手来源。优先公司公告、产品页、论文、作者原访谈；社交转述只作线索。
- 比较事件发生日期与报道日期，不能把旧闻写成“刚刚”；给出本次用到的 1—3 个直接来源链接与日期。
- 区分事实、作者观点、尚未确定的影响。不把标题中使用疑问号当成无证据暗示的许可。
- 热点标题的常用骨架：主体＋新动作；技术变化＋普通人的影响；原有认知＋新证据；双方分歧＋具体问题。没有新证据时，不强行写成“重大突破”。

### 2. DBS 决定怎么产生阅读动机

已安装时读取 `dbs-xhs-title` 当前原文，从话题匹配的公式中选择，保留认知冲突、好奇缺口、权威借力、生活关联等有效逻辑。

- 给采用 DBS 的候选标出真实编号和对应逻辑；例如 #69 是“名人如何实现结果”，不能把所有名人新闻都贴成 #69。
- DBS 公式举例是写法素材；其中“爆款已验证”等说法不构成视频号有效性的证据。必要时展示原例要标明“公式库例句”，不能承诺照用就有流量。
- DBS 原始定位是小红书；不要把其小红书字数要求、长篇展示格式、泛化到所有人的要求当成视频号平台硬规则。本 Skill 的输出按用户已确认的“封面方案＋标题选择”组织。
- 用户提供的事件主体和术语如果是新闻识别入口，应保留；不要为了扩大话题，把有辨识度的 AI 公司、产品或人物全部替换成“赚钱、成功”。
- 已有定稿标题先尊重；用户要求选择时，再提供 DBS 与其他来源的不同方案。
- 某个公式要求没有依据的数字、秘密、唯一办法或绝对结果时，换公式，不补造事实。

### 3. 竞品决定如何让主题、字、图联动

以下是参考封面中的主题结构，全部只作表达分析；不代表所涉新闻、产品名称、数字或预言已经核实。不能从封面推出视频完整口播，也不能从可见互动数字推断设计因果。

| 竞品中的结构 | 对应题材样本 | 可复用的视觉机制 |
|---|---|---|
| 人物＋反常行动＋规模 | 马斯克与芯片厂 | 新闻主角＋巨大工厂，贝拉作解说者 |
| 技术突破＋熟悉的难题 | AI与数学 | 一个能看懂的问题符号＋人物反应 |
| 技术扩张＋谁承担代价 | AI成本、消费者买单 | 芯片或产品＋明确的影响物体 |
| 多方分歧＋行动冲突 | AI巨头刹车 | 人物关系＋道路/停止等视觉比喻 |
| 抽象原理＋日常动词 | AI“长”出来 | 用生长、空间或物体说明概念 |
| 新产品＋旧方式变化 | Cybercab与汽车生意 | 新产品成为中景主角，背景解释旧场景 |
| 权威观点＋未来后果 | 研究员警告 | 真人思考＋克制的专题环境；不要照抄恐惧强度 |

从结构里提炼当前内容的真实反差，再决定标题和画面。不是逐字替换竞品标题中的名字，也不是所有标题都写“疯了、颠覆、失控”。

## 可建议的其他视觉方向

默认风格仍是已建立的青柠/玫粉科技海报。根据内容，可再给 1—2 个对照方向，保留本人辨识度和品牌强调色；下列是建议分支，不是自动替代用户默认风格。

| 建议方向 | 适合内容 | 与默认方案的实际区别 |
|---|---|---|
| 沉思型科技专题 | 观点、研究争议、深度解释 | 真人更大，书桌/办公室背景，暖肤色与冷环境，减少发光元素 |
| 产品主视觉 | 机器人、硬件、可见成果 | 产品占更多面积，简洁舞台与材质光，人物退为解说者 |
| 真实场景新闻感 | 工作生活影响、实测 | 用真实场景和真实成果承接标题，少用虚拟蓝图与概念粒子 |

用户明确要求找网上的视觉参考时，实际搜索并查看与选题匹配的案例；每例给原始来源和“借鉴哪一点”。不要把未看过的网页或自己想出的风格当作已找到的参考。

## 建议的方案展示

1. 用一句话概括本期事件与可视化主题。
2. 标题选择表：约 5 个候选／来源逻辑／吸引点／必要的事实条件；明确推荐一项。
3. 推荐构图：标题分行、青柠词组、人物动作、主题物、背景和玫粉位置。
4. 1—2 个可选视觉方向，每个只说明关键差异和适配理由。
5. 有联网核验时附来源；让用户确认标题和视觉方向后再生成图片。
