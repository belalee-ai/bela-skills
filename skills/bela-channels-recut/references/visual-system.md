# 视觉系统

## 版式（1080×1920）

| 层 | 位置 | 规则 |
|---|---|---|
| 背景 | 全屏 | 见下方背景方案，默认 A；不抢主画面，中间压暗 |
| 标题 | top 150 | 两行固定全程：第一行白色，第二行主题色；思源黑体 700（OPPO Sans 有了就换），右倾 12° |
| 账号名 | 标题下 top≈372 | 可选「— @贝拉的科技手记 —」28px、55% 白，不放第二处 |
| 素材带 | top 420，1080×596 | 实拍视频，cover 填满，每镜带轻微推拉/横移 |
| 字幕 | 素材下方约 60px | 中文白色得意黑 ≤68px，英文白色斜体 ≤44px，无底色、带暗投影 |
| 小圆镜 | 居中，top 1270，直径 400 | 取原片 1080 宽、中心 y≈690 的方形：完整头顶 + 少量空白，下到胸口；白色细边 |

开头大人像全屏（标题叠在上面，顶部压暗），只放第一句问候或钩子，通常 1 秒左右；**说到下一句、下一个冲突点时** 0.4 秒缩成圆镜并出现素材带（不以提到人物为准）；结尾最后约 10 秒放大回大人像，配 3–4 次 1.0↔1.1 推近和花字。

## 花字

字体：数字、英文 Orbitron 900；汉字思源黑体 900。白字 + 暗投影，**不加荧光**；保留青柠绿四角框作为统一识别。

**选型表（草案，待多轮测试定版）：按内容选动效，相邻两个花字不能用同一种动效。每次新片先做一段含 3–4 种花字的样片给用户看，用户的取舍记进复盘日志，再调整本表。**

| 内容类型 | 动效 | 音效 |
|---|---|---|
| 年份、数量（2030、7 个、4 年） | 数字快速翻滚后落定，单位再逐字弹出 | 每跳一下 tick，落定 lock |
| 前后对比（100 年 vs 10 年） | 双行计数 + 进度条：慢的慢慢滚满，快的瞬间跳到；底下实拍压暗 | tick 连发 + lock |
| 最 / 第一 / 首家 / 快 N 倍 | 放大砸入 + 画面震动 + 闪白 | 低音冲击 bass-hit |
| 关键词（超乎想象、学会用火） | 逐字弹出 | 每字 blip |
| 英文术语（Species Level Transition） | 打字机逐字母 + 中文释义 | 键盘/blip |
| 问句（谁在用？学历？存款？） | 问号先弹出再出字，或左右分屏两问 | blip |
| 否定/警示（先别迈、没有意识） | 划线或 ✕ 盖章 | lock |
| 两项并列（两道线） | 两条线依次画出 + 标签 | data |
| 人物出场 | 左下名字条（绿竖线 + 中文名 + 英文职衔） | data |
| 章节「第 N 个」 | 左上「第 N 个 N/7」滑入 + 闪白 | sci-fi sweep |

1102 案例的问题：除数字翻滚外全是同一种「逐字弹出 + 四角框」，用户指出单一。新片按上表至少用到 5 种。

## 音效

本地合成（`sfx-src/make_sfx.py`）：tick、lock、blip、data、bass-hit-short、sweep-scifi-fast。音量（线性，再乘统一增益 `SFX_GAIN = 0.9`）：blip 0.14–0.16、tick 0.14、lock 0.2、data 0.12、sweep 0.2、bass 0.4，人声为主。用户 2026-11-03 说音效偏高，整体降 10%；以后整体调大小只改 `SFX_GAIN`。每个变化节点都要有声音或画面变化之一。
