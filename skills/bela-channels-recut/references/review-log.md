# 复盘日志

每次使用本 Skill 后追加。格式：日期｜案例｜用户纠正（原话要点）｜根因｜已改进到哪一条规则｜状态。

## 每日复盘流程

1. 找出当天用到本 Skill 的对话（会话记录里出现 bela-channels-recut、视频号复刻、精剪初版等）。
2. 把用户的纠正和返工逐条归类：素材 / 节奏 / 口播剪口 / 字幕 / 花字动效 / 人像版式 / 声音 / 工程故障。
3. 按「出现次数 × 返工代价」排序，挑**最需要解决的 3 个问题**。
4. 每个问题写：现象、根因、建议改哪个文件哪一条、怎么验证。
5. 发给用户确认；确认后再改 SKILL.md 或 references，`metadata.version` 加一位，在下面记一行。
