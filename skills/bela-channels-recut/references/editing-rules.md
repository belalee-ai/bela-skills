# 口播粗剪规则

## 删什么

- 停顿：超过 0.5–0.6 秒的一律压到约 0.1–0.3 秒（问句、金句后可留到 0.4 秒）。用户点名的停顿必须处理。
- 重复：重复的字、词；说了半句发现不对又重说的，**删前面那半句**，保留完整的那遍。
- 卡壳：卡在半句再重来，删卡住的部分，从重来那遍接上。
- 口癖和口气：呃、嗯、额、那个、就是（无意义时）、明显的吸气声。
- 同一段说两遍（如两次「第五个」），保留更完整、更顺的那遍，通常是后一遍。

## 不吞字（最容易出错）

1. 切点只放在**能量谷**里：用 16 kHz 单声道音频算 30 ms 一格的 RMS 包络，找字与字之间低于 -45 dB 的谷，切在谷中间。
2. Whisper 的词级时间只用来**定位**，不能当切点：它常把字尾算短。1102 案例里「过得好」的「好」到 188.26 秒才结束，词级时间却给到 188.20，按它切把「好」吞了。
3. 每个剪口两边各留 15 ms 淡入淡出（脚本已带），不用长淡化掩盖切坏的字。
4. 原片里某个字自己就没说完整：**不硬拼，请用户补录这一句**。

## 切点定位流程

1. `mlx_whisper 原音频 --word-timestamps True --condition-on-previous-text False --hallucination-silence-threshold 1`（不关 condition 会在长段里循环乱码）。
2. 对可疑处（重说、卡壳、ASR 出现重复词）截 1–3 秒小段单独再转写，确认到底说了什么。
3. `ffmpeg silencedetect=n=-38dB:d=0.2` 列出所有停顿，配合能量包络定边界。
4. 写 `keep.json`，`python3 scripts/rough_cut.py 原视频.MOV 粗剪.mp4 1.2 keep.json`。

## 改剪口后的同步

粗剪变了，成片时间轴整体后移/前移。用 `scripts/shift_times.py <data.ts> <切点成片秒> <减少秒数>` 平移 data.ts 里切点之后的所有时间（from/to/at 和 IMPACTS、PUNCH_INS、TOTAL_SECONDS）；落在被删区间里的值会钉到切点。素材入点 `start` 不动。

## 验收

- 粗剪完成后**重新转写整条粗剪**，逐句对照：没有重复、没有半句、每句完整。
- 每个新剪口截前后 4 秒再转写，确认两边字都完整、中间没有残音；同时看能量包络里剪口两边是否有完整的字尾衰减。
- 我不能真的「听」：交付时写明「已转写核对，未实际回听」，请用户回听重点剪口。
