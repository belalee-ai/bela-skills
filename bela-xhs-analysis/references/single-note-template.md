# 单篇笔记深度拆解模板

> v0.3.0 起所有单笔记 `.md` 必须以 YAML front matter 起头。字段与 `references/meta-json-schema.md` 中的 `notes_index` 元素一一对应。

## 文件头 · YAML Front Matter（标准字段，下游 skill 依赖）

每篇笔记 `.md` 必须以 YAML front matter 起头：

```yaml
---
date: 2025-11-15              # 笔记发布日期 YYYY-MM-DD
slug: github三步上手           # 文件名 stem（与 _meta.json 同名）
title: 普通人学AI必看，GitHub三步上手
url: https://www.xiaohongshu.com/discovery/item/...?xsec_token=...
likes: 13
collects: 2644
comments: 23
format: 图文                   # 图文 | 视频
is_explosive: true             # 按当时粉丝阈值判定
tags: [人工智能, 大模型, AI工具]
scraped_at: 2026-05-28T14:30:00+08:00
deep_scraped: true
asr_extracted: false
comments_disabled: false
---
```

**字段规则**：
- 字段名 **= 下游 skill 写死的依赖**，不许改名（只能加，不能删/改）
- 任何字段重命名都需升 `schema_version`
- 详细字段表见 `references/meta-json-schema.md`

---
