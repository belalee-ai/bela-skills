## v0.3.0 新增 · README.md 标准结构（对标博主库专用）

每个博主目录 `{storage_root}/{行业}/{平台}-{博主名}/README.md` 必须包含以下 **7 段**（按顺序）：

1. **顶部** — 博主基本信息 + 上次扫描时间
2. **博主画像** — 粉丝 / 简介 / IP / 小红书号 / 历史粉丝量
3. **内容形式分布** — 图文/视频占比（自动统计）
4. **选题主题分布** — AI 归纳 + 篇数 + 爆文数（标"AI 整理 · 可被你否决"）
5. **笔记总览表（10 列）** — 半年内笔记，时间倒序
6. **爆文榜** — 按当前 `explosive_threshold` 筛选
7. **评论区高频诉求 TOP 3** — 双轨格式（每类挂 ≥ 2 条原文证据）

### 10 列字段对照表

| 列名 | 数据源（`_meta.json.notes_index` 字段） |
|---|---|
| 日期 | `date` |
| 封面 | `slug` → `images/covers/{slug}.webp` |
| 标题 | `title` |
| 链接 | `url`（保留完整 `xsec_token`） |
| 形式 | `format` |
| 点赞 | `likes` |
| 收藏 | `collects` |
| 评论 | `comments` |
| 是否爆文 | `is_explosive` |
| 详情 | `file`（相对路径） |

### 评论 top3 类 · 双轨标准格式（C2 宪法核心）

```markdown
## 评论区高频诉求 TOP 3（合并爆文样本 · 每类挂原文证据）

### ① {分类名}（{N} 条）
- "{原文 1}" · {N}赞
- "{原文 2}" · {N}赞

### ② {分类名}（{N} 条）
- "{原文 1}" · {N}赞
- "{原文 2}" · {N}赞

### ③ {分类名}（{N} 条）
- "{原文 1}" · {N}赞
- "{原文 2}" · {N}赞
```

**硬规则**（实现于 `scripts/library/classify_comments.py`）：

- ✅ 每个分类必须挂 **≥ 2 条**原文证据
- ✅ 原文必须从 top 10 评论实际抓取，AI 不得编造
- ⚠️ 评论 < 10 条时**不归类**，直接列原文 + 标注「评论较少，未做归类」
- ⛔ 评论关闭时**不出此段**，README 标注「评论已关」
- ⛔ 任何挂不到 2 条证据的"分类"被自动剔除

### 评论较少 fallback 格式

```markdown
## 评论 top {N}（评论较少，未做归类）

1. "{原文}" · {N}赞
2. "{原文}" · {N}赞
...
```

### 评论关闭 fallback 格式

```markdown
## 评论

评论已关 · 未抓取.
```

## 与 `_meta.json` 的关系

| 文档 | 角色 |
|---|---|
| `README.md` | 人读的视图，可读性优先 |
| `_meta.json` | 机器读的契约，结构化、稳定 |
| `notes/{slug}.md` | 单篇笔记完整内容（含 YAML + OCR + 评论原文） |

**真理来源**：以 `_meta.json` 为准。`README.md` 是从 `_meta.json` 渲染出的视图。手改 README 会被下次扫描覆盖——要改请改源（`_meta.json` 或 `notes/{slug}.md` 的 YAML）。
