# Bela IP Pic

让贝拉小人物作为 Lidali 的固定本人替身出现在原创视觉作品中，同时保持角色身份、多风格路由和真实证据边界。

## 开始前

1. 完整读取 [references/character-style.md](references/character-style.md)。
2. 生成或编辑图片时使用当前 `imagegen` Skill 的默认内置图片流程。
3. 先确认本次最小交付：用途、画幅、贝拉在做什么、她是主角还是旁白、画面内准确文字。缺少但不影响方向的信息可合理补全，不因普通构图细节停下来追问。
4. 新系列或新视觉方向先生成一张代表性 Demo；单张任务可直接生成。Demo 未确认前不批量扩展。

## 选择画风

角色身份与画风分开管理：发型、脸、服装、比例和右手环始终锁定；线条、材质、留白和色彩按风格分支变化。

- `风格 01｜粗笔涂鸦手绘风`：粗而不均匀的黑色手绘线、平涂和少量颗粒，表情与动作更直接。适合轻教程、反应、吐槽、搞笑动作、表情包和视频边角旁白。正式参考：`assets/bela-style-01-rough-doodle.png`。
- `风格 02｜奶油蜡笔留白手绘风`：暖奶油纸、干蜡笔与彩铅颗粒、大面积留白、少量玫红/橙黄/蓝绿点色，人物更自然克制。适合成长记录、职业思考、AI 实验复盘、生活叙事和情绪性编辑插画。正式参考：`assets/bela-style-02-cream-crayon-editorial.png`。
- `风格 03｜手撕纸贴纸拼贴风`：可见不规则纸片裁切边缘、叠层与轻微纸影，彩铅和蜡笔纹理保留在纸片内部。适合贴纸、封面小剧场、动作卡、片头和较强手作感的单人物画面。正式参考：`assets/bela-style-03-paper-sticker-collage.png`。

用户说“上次/原来的手绘风”时优先理解为风格 01；说“这次/奶油蜡笔/大留白这种手绘风”时使用风格 02；说“贴纸风/手撕纸/拼贴风”时使用风格 03。未点名时，轻教程和高能反应默认风格 01，成长与复盘内容优先风格 02，明确需要贴纸或拼贴效果时使用风格 03；仍无法判断时沿用当前系列已使用的分支。未经要求不要在同一张图里混合不同风格。

## 选择参考图

生成前必须实际查看需要的参考图，不能只凭文字描述：

- 默认正面与小比例旁白：`assets/bela-reference-narrator.png`
- 蹲下、观察或动手场景：`assets/bela-reference-crouch.png`
- 张开双臂、主讲或全身展示：`assets/bela-reference-open-arms.png`

每次选择最接近目标动作的 1–2 张贝拉参考图即可。若还要带其他角色或版式参考，把输入图总数控制在当前图片工具可接受范围内，并明确每张图是角色参考、风格参考还是编辑目标。

每次至少加入一张角色参考图和一张所选风格的正式参考图。角色参考负责身份，风格参考只负责线条、材质、色彩和留白，不能让风格参考中的人物、道具或构图覆盖本次内容。

## 复用已有动作

用户提供自己的动作库时，先检查候选参考图，选择与当前风格和动作匹配的素材。

## 使用方式

### 新生成

- 贝拉是画面主角时，占画面高度约 35%–55%；作为陪伴或旁白时，占约 12%–25%。
- 每幅只让她做一个清楚动作，动作要回应当前主题。
- 同一组作品中变化表情、动作和位置，不连续复制同一站姿。
- 未明确要求时使用默认服装，并按上面的风格路由选择对应分支；不擅自换装或改成 3D、真人、厚涂动漫。
- 有文字时逐字提供原文，要求不增加其他文字；生成后肉眼逐字检查。

### 编辑已有图片

- 先查看当前图片，把它作为第一编辑目标；再加入最接近的贝拉角色参考图。
- 一次只处理一个明确问题，例如修正手环、表情、动作或位置。
- 明确写出保持不变项：其他人物、背景、构图、文字、材质和所有未要求修改的区域。
- 默认非破坏性保存，不覆盖用户原图，除非用户明确要求替换。

### 与真实证据同场

- 真实录屏、截图、界面和结果必须保持原样，不能把贝拉画进按钮、数据、输出或操作过程来冒充真实使用。
- 可让贝拉出现在截图外侧、解释卡、转场、画面边角或结尾，承担观察、指向、反应和串联作用。
- 若画面空间不足，优先保留真实证据完整可读，再缩小贝拉或把她移到相邻画面，不遮挡关键内容。

## 角色连续性

每次提示词都重复这些锁定项，不假设模型记得上一张：黑色短碎发、侧分刘海、头顶小翘发、暖肤色圆脸大眼、珊瑚腮红、约 3.5 头身、默认酒红短款运动背心、炭黑短裤、白灰运动鞋、青柠绿手环固定在她自己的解剖学右手腕。

下半身固定为宽松短裤遮住大部分腿根、两截干净的小直腿和略大的运动鞋；不画鼓胀大腿、膝盖肉褶、腿部肌肉解剖或肉感阴影。

身份锚点保持不变；动作、表情、大小和站位根据内容变化。确需换装时仍保留发型、脸、右手环、头身比例和行动派气质。

## 验收

- 第一眼能认出是同一个贝拉，而不是普通短发女孩。
- 手环在贝拉自己的解剖学右手腕，转身或换边后没有戴反。
- 发型、脸、默认服装、鞋子和头身比例没有漂移。
- 所选分支的线条、材质、留白和点色规则仍在，没有漂移或与另一分支混用。
- 动作服务当前内容，同组作品没有复制粘贴感。
- 中文原文准确，没有多字、错字或水印。
- 真实录屏、截图和结果没有被插画篡改或冒充。

未通过时只做一次单点修正，再重新查看成片。最终报告保存路径、画幅、使用的参考图和当前状态；项目使用的确认图必须保存进项目目录。
