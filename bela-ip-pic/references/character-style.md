# 贝拉小人物 IP 角色与多风格规范

## 1. 角色定位

贝拉小人物是 Lidali 在原创视觉作品里的固定本人替身。她承担在场、观察、提问、动手、解释和给出判断的作用，更像一个鲜活、敢试、会亲自下场的行动者，不是纯装饰贴纸，也不摆专家或导师姿态。

在 AI 账号原创视觉作品中默认让贝拉出现。真实录屏、真实截图和真实结果保持原样；贝拉可以安排在开场、转场、解释页、画面边角、结果旁白或结尾。

## 2. 不可变身份锚点

- 黑色短碎发，侧分刘海，发尾略翘，头顶保留一小撮自然翘起的头发。
- 暖肤色圆脸，大而有神的深色眼睛，细黑眉，小鼻子，珊瑚粉腮红。
- 儿童绘本式约 3.5 头身；头略大、四肢短而灵活，不画成幼儿或高挑时装人物。
- 默认穿酒红色短款运动背心，领口和袖口有深色或暖白细边。
- 炭黑色运动短裤，带铅笔排线和轻微布料纹理。
- 白灰色运动鞋。
- 青柠绿色手环固定戴在角色自己的解剖学右手腕；角色转身、侧身或换边时不能换腕。
- 下半身采用宽松短裤、两截干净的小直腿和略大的运动鞋；不画鼓胀大腿、膝盖肉褶、腿部肌肉解剖或肉感阴影。
- 整体气质外向、机灵、有行动力，表情生动但不过分幼态。

确有场景需要时可以换装，但黑色短碎发、圆脸大眼、珊瑚腮红、青柠绿右手环、3.5 头身和行动派气质必须保留。未明确要求时使用默认服装。

## 3. 动作与表情

动作可使用：叉腰、张开双臂、指向重点、蹲下观察、拿放大镜、抱资料、思考、试错、庆祝、探头或从画面边缘进入。

表情可使用：好奇、惊讶、犯难、专注、恍然大悟、得意、轻微吐槽和开心。

动作、表情、大小和位置必须随内容变化。贝拉可以是主角、讲解人、边角旁白，也可以与其他角色同场；不要连续多页复制同一站姿。

## 4. 画风分支

所有分支共享角色身份锚点，但线条、材质、留白和点色不可混用。

### 风格 01｜粗笔涂鸦手绘风

- 粗而不均匀的黑色手绘线，轮廓直接，允许轻微错位和涂出边缘。
- 平面色块为主，阴影很少；保留纸张颗粒、蜡笔摩擦和随手画的笨拙感。
- 表情和动作可适度夸张，缩小时仍能读懂，适合高频表情与视频角标。
- 常用色为暖米白、酒红、炭黑和青柠绿，其他颜色只作少量强调。
- 正式参考：`../assets/bela-style-01-rough-doodle.png`。

### 风格 02｜奶油蜡笔留白手绘风

- 暖奶油色无涂层纸张，可见纤维、旧纸颗粒和轻微擦痕。
- 干蜡笔、油画棒与彩铅叠加；黑色线稿松动、断续、有真实手压颗粒。
- 人物五官更自然克制，保留本人短发和表情，但减少日漫放大感。
- 画面保留大面积空白，只用 2–3 个抽象手绘轨迹、色块或小符号回应主题。
- 以酒红、炭黑和暖米白锁定人物，玫红、橙黄、灰蓝、嫩绿作为少量点色。
- 适合成长、职业、复盘和生活叙事，不照搬风格参考里的角色、道具或构图。
- 正式参考：`../assets/bela-style-02-cream-crayon-editorial.png`。

### 风格 03｜手撕纸贴纸拼贴风

- 人物由不规则裁切纸片拼合，可见真实纸边、叠层、细小错位与轻微投影。
- 纸片内部保留彩铅、蜡笔和纸纤维，不做光滑矢量贴纸或塑料立体贴纸。
- 头发、脸、手臂、服装、腿和鞋均保持清楚的独立纸片结构，动作一眼可读。
- 下半身必须是宽松短裤遮住腿根、两条均匀小直腿和略大的运动鞋；严禁肌肉腿、鼓胀大腿、膝盖肉褶与腿部解剖阴影。
- 适合贴纸、封面小剧场、动作卡、片头和单人物手作视觉；背景保持暖奶油纸与充足留白。
- 正式参考：`../assets/bela-style-03-paper-sticker-collage.png`。

三种风格都避免：3D 玩具感、扁平矢量、日系厚涂、写实人像、塑料高光、赛博蓝紫光、复杂 UI、过度精致的商业插画、背景塞满道具、人物像同一姿势复制粘贴。

## 5. 构图规则

- 每幅只让贝拉做一个清楚动作，不为露出 IP 抢走主内容。
- 主讲时可占画面高度约 35%–55%；陪伴或旁白时约占 12%–25%。
- 标题通常放在顶部 10%–22%，人物主要位于中下部或画面侧边，保留手机端安全边距。
- 与阿朱、阿兔同场时保持同一种彩铅淡水彩材质和相近头身比例；贝拉始终是人类角色。
- 同组画面保持发型、默认服装、右手环和鞋子一致，主动变化动作、表情和站位。
