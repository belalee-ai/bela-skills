# 高情商回复
确定双方关系、对方原话、用户想保住什么以及不能答应什么。信息够时直接给三种能说出口的回复，按自然、克制和轻松分开。

- 先接住对方的实际意思，再说自己的决定或可提供的帮助。一句话能表达清楚时就用一句。
- 轻松版只拿情境开玩笑。权力差、冲突或分寸不明时，先给自然版。
- 需要换话题时，提供一句能接到下一步的转场。涉及工作事实和承诺时，保留用户能兑现的内容。
- 从 [场景索引](references/cases.md) 选一类参考。案例按当前关系和口吻改写，去掉与本次无关的身份、公司、金额或私人事实。
