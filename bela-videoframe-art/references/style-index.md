# Style index

Choose by what the frame can afford to lose and which source property can become the image's construction rule. Color preference is secondary.

## Routing axes

Assess these axes before recommending:

1. `negative_space` — can the event survive after 55% or more of the frame becomes quiet?
2. `line_rhythm` — does the source contain real stripes, spokes, slats, folds, rails, branches, or support structures?
3. `material_anchor` — does wood, metal, cloth, brick, soil, paper, or another surface carry meaning?
4. `collage_layers` — are there at least two separable depth planes or image fragments that can overlap without losing the event?
5. `route_or_boundary` — is there a road, shoreline, river, path, horizon, or movement trajectory that can become a graphic line?
6. `value_silhouette` — does the hero remain recognizable in one or two tones?
7. `recognition_anchors` — which maximum four cues must remain for the image to be traceable?

## Batch distinction

For a multi-style request, reuse the same event and recognition anchors but honor each style's own composition-change level. Do not lock the same crop across the batch: that neutralizes the difference between collage, grid, print, and high-negative-space styles. Keep the output ratio identical unless the user asks otherwise. Reject any batch where two outputs differ mainly by palette.
